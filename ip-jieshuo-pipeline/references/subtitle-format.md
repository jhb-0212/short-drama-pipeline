# 字幕稿 + SRT 规范（Subtitle Format）

> 定位：解说成片流水线的**阶段④产出**。把旁白稿的主字幕 + 强调字幕，转成可直接用的 SRT 时间轴 + 离线看板。
> 铁律：字幕是「主字幕（旁白全文）+ 强调字幕（关键数字/金句）」两级，时间轴按语速分配。

---

## 一、字幕两级

| 级别 | 内容 | 样式 |
|---|---|---|
| 主字幕 | 旁白全文（`subtitle_main`） | 常规字号，底部居中 |
| 强调字幕 | 关键数字/金句（`subtitle_emph`） | 放大、加粗、定格 |

---

## 二、SRT 时间轴分配规则

- **逐段时长**：`段时长 = 段字数 ÷ 语速`（与旁白稿校验一致）
- **时间轴**：`V01` 从 0 开始，逐段累加段时长
- **SRT 内容**：主字幕（旁白全文）。强调字幕可作为第二条字幕叠在同时间段，或写进主字幕用 `**加粗**` 标记。

### SRT 示例

```
1
00:00:00,000 --> 00:00:03,800
他活了83岁，却只被记住最后10秒。

2
00:00:03,800 --> 00:00:07,200
（下一段旁白）
```

---

## 三、字幕字数与语速校验（V8 检查码）

- 主字幕 = 旁白全文，字数应与 `narration` 一致（脚本 V8 比对 `subtitle_main` 与 `narration` 是否一致，防字幕稿与旁白稿漂移）。
- 强调字幕（`subtitle_emph`）若填写，必须是主字幕里的子串（关键数字/金句），不能凭空多出旁白里没有的字。

---

## 四、离线看板（board.py 产出）

解说看板单文件 HTML，串起「旁白 + 素材 + 字幕 + 提示词」四份对齐：

| 列 | 来源 |
|---|---|
| 段落号 | `id`（V01/…） |
| 结构角色 | `role`（钩子/背景/主体/高潮/落点） |
| 旁白 | `narration` |
| 素材方向 | `asset_dir`（锚定素材匹配表） |
| 版权 | `copyright` |
| 字幕 | `subtitle_main` + `subtitle_emph` |
| 提示词 | 两段式成片提示词 |

同时导出：`*.srt`（字幕时间轴）、`*.csv`（剪辑时间线）。
