# 素材匹配表规范（Asset Match）

> 定位：解说成片流水线的**阶段②产出**。把剧本层画面提示表 + 旁白稿，落成「一段旁白 → 一条素材方向 + 版权状态」的可执行匹配表。
> 铁律：素材方向**锚定画面提示表**，成片时禁止凭空换素材（换了就漂移）。版权是解说的生命线，每条素材必标版权状态。
> **版权唯一真源**：`copyright` 字段只在素材匹配表（本文件）出现，旁白稿 `vo.json` 不承载版权字段（见 `vo-format.md`）。V7 版权校验只读本文件的 `copyright` + `license_note`。

---

## 一、素材匹配表结构

```json
{
  "title": "他活了83岁，却只被记住最后10秒",
  "source": "混搭",              // 实拍 / 历史影像 / 图文动画 / 混搭
  "segments": [
    {
      "id": "V01",
      "asset_dir": "老照片/画像",   // 素材方向（锚定画面提示表）
      "asset_src": "历史影像",     // 素材来源类型
      "copyright": "需授权",       // 公共领域 / 需授权 / 自摄
      "license_note": "XX档案馆藏，需购买授权"   // 授权说明/出处
    }
  ]
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `segments[].id` | ✅ | 段落号 `V01`，与旁白稿、字幕稿、提示词对齐 |
| `segments[].asset_dir` | ✅ | 素材方向（锚定画面提示表 `visual_hint`） |
| `segments[].asset_src` | ✅ | 素材来源类型：实拍 / 历史影像 / 图文动画 |
| `segments[].copyright` | ✅ | 版权状态：公共领域 / 需授权 / 自摄 |
| `segments[].license_note` | ⭕ | 授权说明或出处（需授权时强烈建议填） |

---

## 二、版权分级（V7 检查码）

| 版权状态 | 含义 | 处理 |
|---|---|---|
| 公共领域 | 已过版权期 / CC0，可免费商用 | 直接可用 |
| 需授权 | 有版权，需购买/取得授权 | **必须填 `license_note`**（出处/授权方） |
| 自摄 | 自己拍摄/制作 | 可用，标注拍摄来源 |

**纪律**：
- 「需授权」素材**必填 `license_note`**，否则 V7 报「版权缺失」。
- 历史影像/图片版权风险高，优先用「公共领域」素材（博物馆公开图库、公共领域影像库）。
- 科普类示意图优先「自摄」（自己做的图文动画），规避版权风险。

## 三、素材方向 vs 分镜（硬提醒）

| 维度 | 解说素材匹配 | 分镜（ip-make-pipeline） |
|---|---|---|
| 粒度 | 一段旁白 → 一条素材方向 | 逐镜 → 站位/运镜/景别 |
| 产物 | 素材方向 + 版权 | 11 字段分镜表 |
| 工具 | 不跑 `asset_check.py` | 跑 `asset_check.py`（资产编号） |

解说类**没有资产编号（P/S/D/V）那套**，因为它没有「同一角色跨镜换脸」的问题——素材是「找现成的」，不是「生成同一角色」。所以素材匹配表**不做** A/B/C 资产分级，只做「方向 + 版权」。

## 四、三类解说的素材方向差异

| 解说类型 | 典型素材方向 |
|---|---|
| 历史人物志 | 老照片 / 画像 / 史料影像 / 地图 / 文献实物 |
| 事件战役 | 战场地图 / 时序动画 / 历史影像 / 双方示意图 |
| 科普知识 | 示意图 / 数据图表 / 实物图 / 动画演示 |
