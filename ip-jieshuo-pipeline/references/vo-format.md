# 旁白稿字段规范（VO Script）

> 定位：解说成片流水线的**输入契约**。旁白稿由剧本层 `ip-script-pipeline/references/jieshuo-script.md` 产出，本文件定义它在成片环节的**结构化 JSON schema**（脚本消费）+ 语速/时长/违禁词校验规则。
> 铁律：旁白稿是「第三人称叙事口吻」，不是角色对白；逐段一个信息点，不堆信息。

---

## 一、旁白稿 JSON 结构

```json
{
  "title": "他活了83岁，却只被记住最后10秒",
  "type": "历史人物志",            // 历史人物志 / 事件战役 / 科普知识
  "duration": 60,                  // 总时长（秒）
  "rate": 5.0,                     // 语速（字/秒，4.5~6.5）
  "aspect": "16:9",                // 画幅（前置锁 F：16:9 / 9:16）
  "segments": [
    {
      "id": "V01",
      "role": "钩子",             // 钩子 / 背景 / 主体 / 高潮 / 落点
      "narration": "他活了 83 岁，却只被记住最后 10 秒。",
      "chars": 19,                 // 旁白字数（校验用）
      "visual_hint": "老照片/画像 + 定格",   // 画面提示（找素材方向，不是分镜）
      "subtitle_main": "他活了83岁，却只被记住最后10秒。",   // 主字幕（旁白全文）
      "subtitle_emph": "最后10秒"   // 强调字幕（关键数字/金句，可空）
    }
  ]
}
```

> 注意：**版权状态（copyright）不属于旁白稿**，它是「素材」属性，归素材匹配表 `assets.json`（见 `asset-match.md`）承载，V7 版权校验只读素材匹配表。旁白稿只管「文字 + 画面提示方向」，不承载版权字段。

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 片子标题 |
| `type` | ✅ | 三类之一：历史人物志 / 事件战役 / 科普知识 |
| `duration` | ✅ | 总时长（秒） |
| `rate` | ✅ | 语速（字/秒），默认 5.0 |
| `aspect` | ✅ | 画幅（前置锁 F），16:9 / 9:16，`prompt_build.py` 读它写入成片提示词【画面】段 |
| `segments[].id` | ✅ | 段落号 `V01/V02/…`，全片唯一，四份文件对齐锚点 |
| `segments[].role` | ✅ | 结构角色：钩子 / 背景 / 主体 / 高潮 / 落点 |
| `segments[].narration` | ✅ | 旁白正文（第三人称叙事口吻） |
| `segments[].chars` | ✅ | 旁白字数（脚本自动重算，勿手填错误值） |
| `segments[].visual_hint` | ✅ | 画面提示（素材方向，非分镜） |
| `segments[].subtitle_main` | ✅ | 主字幕（旁白全文） |
| `segments[].subtitle_emph` | ⭕ | 强调字幕（关键数字/金句，可空） |

---

## 二、语速与时长校验（V2/V3 检查码）

**核心公式**：`旁白总字数 ÷ 语速 ≤ 总时长`

- 总字数 = Σ 每段 `narration` 字数（中文按字，去空白）
- 语速：4.5~6.5 字/秒（解说稍慢更稳，默认 5.0）
- 超时 → 删词或加时长，机械检查拦下（V2）

**逐段时长估算**（供字幕 SRT 分配时长）：`段时长 = 段字数 ÷ 语速`

## 三、违禁词（V6 检查码）

解说类同样受合规约束，命中即报（借鉴 `ip-make-pipeline` 闸门5，但按解说场景裁剪）：

| 类别 | 违禁词（示例） |
|---|---|
| 绝对化 | 最好、第一、顶级、唯一、100%、国家级、世界之最 |
| 虚假功效 | 根治、包治、特效药、长生不老 |
| 迷信/伪科学 | 转运、改命、灵丹（科普类尤其敏感） |
| 历史不严谨 | （历史类）把野史当正史、演义当史实的表述，由考据环节把关 |

> 脚本 `validate.py` V6 检查「绝对化 + 虚假功效」两类机械可查的；历史真实性靠考据环节，不靠机械。

---

## 四、边界（硬提醒）

1. **不做分镜**：旁白稿的 `visual_hint` 是「找素材的方向」，不是「镜头调度」。不要往旁白稿里塞站位/轴线/运镜/景别。
2. **不套台词七维**：旁白是第三人称叙事，不是角色对白，不要用「台词七维诊断」去审旁白稿。
3. **字数必校验**：先算字数再写，防止写超时长（对应剧本层解说链「字数预算」）。
