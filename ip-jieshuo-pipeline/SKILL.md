# IP 解说成片流水线（ip-jieshuo-pipeline）

> 定位：衔接 `ip-script-pipeline`（剧本层赛道③解说叙事）与素材剪辑/图文成片工具。剧本层产出「解说稿 package（旁白稿 + 画面提示表 + 字幕稿 + 考据来源）」，本流水线把它们**消费**成可剪辑/可生成的「素材匹配表 + 成片提示词 + 字幕 SRT + 离线解说看板」。
> 铁律：解说类**不做分镜**（没有站位/轴线/运镜/景别那套），它的成片是「**一段旁白配一段素材**」。本流水线与 `ip-make-pipeline`（分镜流水线）是**两条平行线**，不要拿分镜规则来套解说稿。

> **三条核心承诺**（都有脚本落地，不是口号）：
> - **不漂移**：旁白 → 素材 → 字幕三者按段落号（`V01/V02/…`）对齐，素材方向锚定画面提示表，不凭空换素材 → `validate.py` V03 对齐检查
> - **不返工**：语速/时长/版权/违禁词拦在剪辑之前 → 🔒 前置锁 + V 系列检查码 + 三道闸门
> - **能直接投喂**：输出成片提示词 + SRT 字幕，整组复制即可进剪辑/图文生成工具 → `prompt_build.py` + `board.py`

## 🔒 前置锁（动手前强制勾选，硬门不是建议）

> 解说成片同样有前置锁，未指定必须停下询问并摆出选项——禁止默认跳过、禁止替用户推断。

| 锁 | 选项 | 说明 |
|---|---|---|
| **〇·0 赛道确认** | ③ 解说叙事（历史人物志 / 事件战役 / 科普知识） | 第零道锁。确认是解说类才进本流水线；若是国内剧/海外剧，转 `ip-make-pipeline` |
| **A 解说类型** | ① 历史人物志 ② 事件战役 ③ 科普知识 | 决定考据重点、素材方向、提示词风格 |
| **B 时长** | 30s / 60s / 3min / 5min（自由填） | 决定旁白字数预算（时长 × 语速） |
| **C 语速** | 默认 5 字/秒（4.5~6.5 区间） | 与剧本层解说链锁定一致 |
| **D 交付形态** | ① 离线看板 ② 素材匹配表 ③ 两者都交付 | ★ 强制锁，未指定 = 停下询问 |
| **E 素材来源** | ① 实拍 ② 历史影像 ③ 图文动画 ④ 混搭 | 决定画面提示的素材方向与版权标注方式 |
| **F 画幅** | ① 16:9 ② 9:16 | 与图文/剪辑工具同规格前置锁定 |

> 与 `ip-make-pipeline` 前置锁的差异：解说类**没有**「模型版本 / 段缝衔接 / 单镜时长」锁（那是分镜层的），换成「解说类型 / 时长 / 素材来源」三个解说专属锁。

## 四阶段流程

```
① 旁白校验 → ② 素材匹配 → ③ 成片提示词 → ④ 字幕 + 看板
```

| 阶段 | 输入 | 产出 | 规则文件 | 工具 |
|---|---|---|---|---|
| ① 旁白校验 | 解说稿 package（旁白稿） | 旁白稿质检（语速/时长/违禁词） | `references/vo-format.md` | `validate.py` |
| ② 素材匹配 | 画面提示表 | 素材匹配表（段落→素材方向+版权） | `references/asset-match.md` | 人工/agent |
| ③ 成片提示词 | 素材匹配表 + 旁白稿 | 逐段成片提示词（画面/字幕样式） | `references/prompt-guide.md` | `prompt_build.py` |
| ④ 字幕 + 看板 | 旁白稿 + 字幕稿 | SRT + 离线解说看板 + CSV | `references/subtitle-format.md` | `board.py` |

## 三条核心铁律（贯穿全流程）

1. **段落对齐，不漂移**：旁白稿、素材匹配表、字幕稿、提示词**四份文件都按同一个段落号（`V01/V02/…`）对齐**。素材方向锚定画面提示表，成片时禁止凭空换素材（换了就漂移）。

2. **语速与时长硬校验**：`旁白字数 ÷ 语速(4.5~6.5 字/秒) ≤ 总时长`，逐段校验。超了删词或加时长，机械检查拦下超时才进语义审核。

3. **考据与版权是生命线**：历史/科普解说说错、用了无授权素材，都是硬伤。素材匹配表必须标注每条素材的「版权状态」（公共领域 / 需授权 / 自摄），违禁词（绝对化、虚假功效）机械检查拦下。

---

## 经济性（模型分层 + 机械检查优先）

- **便宜模型**做旁白稿搬运、素材匹配表初稿、机械检查；**贵模型**只做成片提示词精修、金句/强调字幕的提炼。
- **机械检查优先**：旁白稿写完先跑 `validate.py`（V1~V8 共 8 条检查码），拦下超时/违禁词/段落不对齐/版权缺失等低级错误，再进语义审核。
