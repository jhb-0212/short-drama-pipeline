# 对标情报搜集（阶段 0 前置输入）

> 定位：阶段 0 `ip-eval` 里「题材热度 / 商业潜力 / 平台匹配」这三个字段，**不能靠模型凭空打点**——它们必须有外部对标情报做锚。本文件定义「对标情报搜集」的规范，产出**对标情报报告**，作为阶段 0 打点与赛道硬分流的输入。
>
> 核心认知：本流水线是「从 IP 出发」的单向链（IP → 剧本 → 分镜 → 成片），缺一条「从市场/对标往回看」的输入线。本文件补上这条线——**先看市场，再定赛道，再进改编**。
>
> 铁律：情报只做「结构化沉淀」，不做「拍脑袋结论」。每个判断都要能回溯到具体作品或数据来源，采不到的一律标「无公开数据」，不硬编。

---

## 一、什么时候做、产出什么

| 项 | 说明 |
|---|---|
| 时机 | 阶段 0 `ip-eval` **之前或并行**——先搜集对标，再用对标给「题材热度 / 平台匹配 / 商业潜力」三项打点 + 「赛道」分流结论 |
| 输入 | 目标 IP 的题材/类型 + 初步赛道意向（若已有） || 产出 | **对标情报报告**（结构拆解表 + 赛道趋势表 + 数据基准【可选】） |
| 模型档位 | 便宜模型（结构化检索 + 搬运，不需要创作力） |
| 门禁 | 对标情报报告字段齐全（见下），才放行阶段 0 的「题材热度 / 平台匹配 / 商业潜力」三项打点 + 「赛道」分流结论 |

---

## 二、对标作品池（先圈样本，再拆）

> 拆解之前，先圈出「拆谁」。样本选错，拆出来的结论全偏。

**选样原则**：
- 同题材 / 同赛道（国内对白剧 / 海外出海 / 解说），3~5 部，宁精勿滥
- 优先「已验证的爆款」（付费榜前列 / 热榜常客），辅以 1 部「中腰部」作对照（看它差在哪）
- 来源：抖音/快手热榜、番茄/七猫付费榜、ReelShort/DramaBox/GoodShort 榜单、B站/西瓜解说热榜（按赛道取对应平台）
- **尚无赛道意向时**：三赛道各采 1~2 部同题材作「初筛样本」，先跑出「赛道趋势表」帮用户定赛道，定完赛道后再补足该赛道的 3~5 部做精细「结构拆解」。避免「先定赛道才能选样本、先选样本才能定赛道」的死循环。

**每部登记一张卡**（缺项标「无公开数据」）：

| 字段 | 说明 |
|---|---|
| 作品名 | + 平台 + 链接 |
| 题材/类型 | 与目标 IP 的对标关系（同题材 / 相邻题材） |
| 体量 | 集数 / 单集时长 / 总时长 |
| 数据信号 | 播放/追读/付费/评分等，能采到的任何量级信号 |
| 采集时间 | 情报会过期，标日期 |

---

## 三、① 结构拆解表（→ 校准 A4 分集规划）

> 对标爆款的「节奏结构」是本流水线最值钱的外部锚点。A4 分集规划里的「钩子分布 + 付费点卡位」现在全靠内推，本表给它外部校准。

每部对标作品拆以下维度（逐部一行）：

| 维度 | 拆什么 | 落点 |
|---|---|---|
| 钩子秒位 | 开场第几秒出钩子、钩子类型（悬念/冲突/奇观/反常识） | 校准 A4「每集钩子点分布」 |
| 单集时长 | 对标单集时长区间 | 校准 A3 开发圣经「平台节奏矩阵」 |
| 付费卡点 | 第几集卡付费、卡在什么情绪顶点 | 校准 A4「付费点卡位」 |
| 反转频率 | 单集几个反转 / 多少秒一个信息爆点 | 校准「钩子密度」 |
| 情绪节拍 | 对标的高潮/反杀落在什么位置（对应情绪 12 节拍） | 校准 A4「情绪节拍曲线」 |
| 开场信息密度 | 前 30 秒交代了几个设定（看它怎么控信息量） | 校准 B 先导片「一句一钩子」 |

**产出**：`结构拆解表`——把 3~5 部的同一维度并排，找出「**共性基准**」（大家都这么干 = 赛道的硬规矩）与「**差异点**」（谁更狠 = 可借鉴的突破口）。

**纪律**：
- 只拆「节奏结构」，不拆「剧情内容」（剧情是原创的，抄剧情 = 侵权；抄节奏 = 学打法）
- 共性基准写进 A4 分集规划的「钩子分布/付费点」时，标注「对标依据：XX 作品」

## 四、② 赛道/题材趋势表（→ 校准阶段 0 硬分流）

> 阶段 0 的「赛道硬分流」决定走国内/海外/解说哪条链，选错 = 全链白干。这个决策最需要对标趋势，而不是纯靠用户拍板或模型猜。

**三个问题逐条答**：

| 问题 | 要结论 | 依据 |
|---|---|---|
| 这个题材现在「热不热」 | 上升期 / 成熟期 / 衰退期 | 近 3~6 个月榜单变化趋势 |
| 它在哪条赛道「更火」 | 国内对白剧 / 海外出海 / 解说，各赛道的热度排序 | 各赛道对标作品数量与数据信号对比 |
| 生命周期还剩多少 | 现在进是「顺势」还是「追尾」 | 题材从峰值到现在的时长 |

**产出**：`赛道趋势表`——题材 × 三赛道 的热度矩阵 + 生命周期判断 + 「建议走哪条赛道」的推荐（**附依据**，不裸给结论）。

**纪律**：
- 趋势判断**必须带时间窗**（近 3 个月 / 近 6 个月），不带时间窗的「火」是耍流氓
- 「建议赛道」是**给阶段 0 硬分流的参考输入**，不是替用户拍板——阶段 0 仍要把三条赛道摆出来让用户确认，但此时已有了对标依据

## 五、③ 数据基准（可选，采不到不强求）

> 短剧的完播率/追读/付费转化多数不公开，强行设为必填只会卡住一个永远填不满的格子。因此**数据基准是可选项**：有就采，没有就标「无公开数据」，并用结构拆解表兜底。

| 指标 | 对标值 | 采集难度 | 兜底 |
|---|---|---|---|
| 完播率 | 同题材对标区间 | 高（少公开） | 用「钩子秒位/单集时长」结构反推 |
| 追读率 / 付费转化 | 同题材对标区间 | 高（少公开） | 用「付费卡点集数」结构反推 |
| 播放量级 | 对标头部/腰部量级 | 中（榜单可估） | 用「榜单排名」代估 |

**纪律**：数据基准**不设必填门槛**——采不到就写「无公开数据」，并注明「以结构拆解表兜底」。禁止编造数据。

---

## 六、与流程的衔接

1. **阶段 0 顺序**：`对标情报搜集（本文件）→ ip-eval 打点（题材热度/平台匹配/商业潜力）→ 赛道硬分流`。没有对标情报，阶段 0 的「题材热度 / 平台匹配 / 商业潜力」三项打点**缺依据**，应标记「待补情报」而非直接打分。
2. **A4 分集规划**：钩子分布 / 付费点卡位时，引用结构拆解表的「共性基准」，标注对标依据。
3. **赛道硬分流**：赛道选择需参考「赛道趋势表」的推荐，而非纯靠用户无依据拍板。
4. **成本**：对标情报搜集用便宜模型，一次搜集，阶段 0 / A4 复用，不重复采集。

---

## 七、边界

1. **只学打法，不抄内容**：拆节奏结构、看赛道趋势是「学打法」；照搬剧情/人物是「抄袭」，红线不碰。
2. **情报会过期**：所有情报带采集时间，超过 3 个月的趋势结论建议重采。
3. **数据不编造**：采不到就是「无公开数据」，用结构拆解兜底，禁止拍脑袋填数字。
4. **不承诺预测**：对标趋势是「降低选错赛道的概率」，不是「保证这部一定爆」。
