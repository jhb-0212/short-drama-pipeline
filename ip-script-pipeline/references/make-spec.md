# 制作层规范（剧本定稿后 → 分镜前 的交接物）

> 定位：这三份是「剧本定稿后、分镜前」必须产出的交接物，属于**制作层**（衔接剧本层与分镜/成片）。剧本层 C5 阶段「提取」产出这三件，字段与铁律**以本文件为准**，不另编字段。
> 原则：这三件是「**提取**」不是「创作」——所有内容必须能在开发圣经或剧本里找到出处，不新造设定。若提取时发现剧本里某道具/角色外貌前后矛盾，回改对应集，而非在清单里硬统一。

---

## 一、人物定妆单

> 剧本定稿后第一件事，是把「人」定下来。AI 生成最大的坑是人物长相漂（同一场戏镜头一换脸就变），根子在没把人物「写死」。这份单子就是写死的地方。一旦定稿，全片所有人物的图、视频都必须照它做，不许中途漂移。

### 字段（每个有台词、有正脸、有戏份的人物，单独一行，全部填满）

| 字段 | 填写要求 |
|---|---|
| 姓名 | 用剧本原文名字，不许自己改字 |
| 身份定位 | 主角 / 配角 / 反派 / 见证者 / 群演（决定资产投入多少） |
| 年龄 | 具体数字，不写「中年/青年」，写「40岁」 |
| 性别 | 男 / 女，必填 |
| 身高体型 | 身高+胖瘦+肩宽体态，如「178cm，偏瘦，肩窄，站姿略含胸」 |
| 脸型五官 | 脸型+眼睛+鼻子+嘴唇+眉毛，逐项写，不能只写「长相普通」 |
| 发型发色 | 长度+造型+颜色，如「短发寸头，黑色，鬓角略长」 |
| 皮肤质感 | 肤色+纹理+有无特征，必须写「无痣无斑」，防止 AI 加斑点 |
| 服装造型 | 整套：上衣/下装/鞋/配饰，颜色材质款式都要写；多套则按场次分开列 |
| 性格关键词 | 3–5 个词，如「沉稳、寡言、护短、认死理」 |
| 行为习惯 | 标志性小动作，如「思考时摸下巴」 |
| 说话方式 | 语速+音量+口头禅，如「语速慢，音量低，爱说『它不挑路』」 |
| 人物关系 | 和谁是什么关系，如「梁小是他弟弟」 |
| 情绪基调 | 全片主要情绪，如「全程隐忍，只在爆发时提高音量」 |
| 参考图 | 定妆图文件名 / 有无参考；有写文件名，无写「需生成」 |

### 三大铁律（踩坑换来的，必须守）

1. **一人一版，绝不换脸**：同一角色从头到尾只有一套面部特征，换装可以，换脸不行。
2. **面部干净光洁**：不得有光斑、亮斑、斑点、痘印、雀斑、疤痕、污渍；皮肤是一整片连续均匀的真实皮肤。
3. **群演各不相同**：一场戏多个人物时，长相、体型、年龄、服装全都不一样，必须有男有女，不许整齐划一。

> **光斑成因**：逆光 + 前景遮挡（树叶、窗格）最常产生光斑。室内或有前景时，改成「柔和正面补光，避免任何遮挡物投影在人物面部」。

### 交付标准

- 人物一个不漏，含只有几句台词的配角
- 每个字段都填满，不留空、不写「同上」
- 服装多套的，按场次分开列，标明第几幕穿哪套
- 定稿后全组共用，后续所有生成以它为准

## 二、剧本简介单

> 作用：让没读过剧本的人（客户/出资方/平台/制作组）30 秒内知道「什么故事、怎么讲、拍出来什么味道、多长」。简介写不好，剧本再好也没人看。
> 适配说明：本模板的「基本信息/分幕结构表」字段（总时长·幕数·镜头数·分幕时长占比）**面向短片（先导片 / TVC / 单集宣传片）**。若用于分集剧本（几十集），「总时长/幕数/镜头数」改为「总集数 / 单集时长 / 单集集均镜头数」，「分幕结构表」改为「分集钩子节奏表」（每集一个 D 节点 + 断点位置），其余字段（片名/类型/题材/风格/色调/参考作品/目标受众/用途/梗概/风格视听定调/主创）通用。

### 结构（五部分）

**① 基本信息**：片名 / 类型（短剧·漫剧·TVC·宣传片）/ 题材（一句话）/ 总时长（精确到秒）/ 幕数 / 镜头数 / 画幅（16:9 横版·9:16 竖版）/ 风格（视觉关键词）/ 色调（主色调+对比关系）/ 参考作品 / 目标受众 / 用途（成片放哪）。

**② 剧情梗概**：只写三件事——谁在哪想干什么；出了什么事打乱；最后怎么解决落到哪。字数 150–300，超 300 说明没提炼清楚。禁止流水账，要能听出「钩子」，听完没有追后文冲动就重写。

**③ 分幕结构表**：每幕一行，写清「讲什么 / 镜头数 / 时长 / 时长占比 / 作用」。这是导演和剪辑的施工图。比例参考（3–5 分钟短片）：建立 10–15%、蓄力 25–30%、高潮 30–40%、释放 15–20%、点题约 5%。**高潮段必须占最长，否则节奏塌，回改结构**。

**④ 风格与视听定调**：视觉风格（写实/动画/二次元/国风/电影感）/ 色调方案（冷暖主调与交替点）/ 光影逻辑（自然光/人工光/逆光/侧光）/ 镜头语言（景别/运镜/慢镜）/ 声音设计（音乐风格/关键音效/旁白）/ 节奏（快切/长镜）/ 禁忌（这片绝对不能出现什么）。

**⑤ 主创与交付**：编剧 / 导演 / 监制 等。

## 三、资产清单表

> 剧本里出现过的每样东西，都得有人做、有地方存、有编号。做不全，剪到一半缺一个背景、缺一件衣服，整条线就得停。**用法：剧本定稿后先做这张表，再拆分镜。分镜表只写「用哪个资产编号」，不再重复描述，避免两处描述打架。**

### 3.1 人物清单

| 字段 | 说明 |
|---|---|
| 编号 | P01/P02… |
| 姓名 / 身份 | 与人物定妆单对应 |
| 出场镜头数 | 翻剧本数「有正脸或有戏」的镜头数，不是台词数 |
| 出场累计时长 | 把出场镜头秒数加起来，判断资产投入值不值得 |
| 出场场次/镜头号 | 具体到哪几场哪几个镜头 |
| 是否需要定妆图 | 需要 / 不需要 |
| 定妆图文件名 | 对应定妆单 |
| 备注 | — |

### 3.2 场景清单

| 字段 | 说明 |
|---|---|
| 编号 | S01/S02… |
| 场景名 / 日夜 / 内外 | — |
| 出场镜头号 / 出现次数 | — |
| 场景资产要求 | 四面图（要拍四个方向）/ 单面图（只一个角度），不是每个场景都要四面图，别浪费算力 |
| 文件名 / 备注 | — |

### 3.3 道具清单

| 字段 | 说明 |
|---|---|
| 编号 | D01/D02… |
| 道具名 / 类别 | 交通 / 生活 / 武器 / 其他 |
| 出场镜头号 / 出现次数 | — |
| 资产要求 | 三视图（正/侧/背，会转动、多角度被拍到才要）/ 单体图（摆着不动） |
| 关键剧情道具 | 是/否。推动剧情的道具（如砸冰的石头、钥匙）必须是三视图，出镜多不能糊 |
| 文件名 / 备注 | — |

### 3.4 声音资产

| 字段 | 说明 |
|---|---|
| 编号 | V01/V02… |

## 与剧本层的关系

- 这三件是剧本层 C5 阶段「提取」产出的配套件，字段与铁律以本文件为准。
- 产出顺序：**剧本定稿 → 做这三件 → 再拆分镜**。分镜表只引用资产编号，不重复描述。
- 它们是剧本层 → 制作层（分镜/成片）的**标准接口**。后续制作层 Skill（分镜/构图/成片）应直接消费本文件的三份清单。

## 三赛道的交接物差异

| 赛道 | 交接给制作层的东西 | 是否需要这三件（定妆单/简介单/资产清单） |
|---|---|---|
| ① 国内剧 | 三件套 + 分集剧本 | ✅ 需要，本文件是标准 |
| ② 海外剧 | 三件套（英文版）+ 英文剧本 | ✅ 需要，但**人物/场景/道具的「英文名 + 本地化描述」**，定妆单里的人名用拼音、描述随文化语境本地化 |
| ③ 解说叙事 | **旁白稿 + 画面提示表 + 字幕稿** | ❌ 不需要——解说类无角色资产，不进分镜，直接进「素材剪辑」 |

> **关键区别**：解说类（③）**不产出这三件**，因为它没有「角色/场景/道具」的资产概念。它的交接物是「旁白稿 package」，走的是「素材剪辑」而非「分镜」。制作层 `ip-make-pipeline` 的分镜/七段式提示词那套，**只对 ①② 适用**，对 ③ 不适用（③ 需要的是另一个「解说成片」流程）。
