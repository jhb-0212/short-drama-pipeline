# 阶段 B · 先导片浓缩（逐步要点）

> 目标：把 A 阶段产出的「highlights（可直用高光片段）」浓缩成一部 **3 分钟左右的独立先导片**。先导片是**独立交付物**，不计入正片集数，用途是低成本验证核心钩子。核心纪律：**只抛问题、不揭答案**，全剧底牌一律留白。

## B0 开写前准备（必做）

1. **读钩子来源判定**：查 A2 的「爽点曲线判定」结论，确定先导片从哪浓缩：
   - **开头即爆** → 从 highlights 里取「开头」段的高光片段浓缩钩子
   - **中后期才爆** → 先补整季爽点曲线，从 highlights 里取「整季卖点」的高光片段反推先导片开场
   - 注意：B 阶段**以 adaptation-package 的 highlights 为素材**，不直接读改编稿全文（highlights 本就是 A 阶段从改编稿里提炼的可直用高光）
2. **锁底牌留白边界**：对照开发圣经「底牌分层 + 揭示节奏表」，确认先导片必须**完全留白**的两层底牌（阴谋层 / 情感层），以及开场不能剧透的核心设定。先导片比正片更严格——**所有底牌都不翻，连「半揭」都不做**。
3. **定浓缩范围**：先导片对应原文前几章（通常第 1–3 章），只取「核心钩子 + 一个视觉奇观 + 一个情感悬念」，不铺开完整剧情。

## B1 浓缩写作

- **模型**：贵模型（先导片是「门面」，错一处影响全剧第一印象，值得一次到位）
- **加载**：adaptation-package 的 highlights + 开发圣经（**不加载改编稿全文**，省 token）
- **写作要点**：
  1. **开场第一秒视觉冲击**：用原文现成的视觉元素（发光之物 / 动作爆发 / 奇观）提到最前，不靠旁白吊人
  2. **一句一个钩子**：旁白/字幕每句只承载一个信息点，不堆叠
  3. **核心设定只点一次**：如「七日倒计时」这类设定，全片只点破一次，后出现时推进新信息、不重复
  4. **次要势力简化**：观众无背景的次要人物/势力（追缉官、影卫）简化或删去，只留一个模糊的「更大威胁」作悬念
  5. **付费卡点断在「危险+悬念」顶点**：断点落在矛盾最大处，不是「减负向」的安慰
  6. **片尾金句用「疑问式留白」**：把核心矛盾摆成问题（"她追他，究竟为印还是另有图谋？"），不点破答案、不用方向含糊的句子
  7. **关键动作补「动作链」**：撬锁/逃生/打斗等拆成 3–4 个可拍节拍（见 `quality-modules.md`）

## B2 机械检查（写完即跑）

- 时长是否 ≤ 3 分钟、场次 ≤ 7（超出 → 合并相邻场）
- 开场字幕是否剧透核心设定（只标氛围/地点/时间，不标「这是什么东西」）
- 同一句台词有无跨场重复
- 同一设定有无在 3 分钟内重复点破

## B3 轻量剧透审查（阶段 B 的唯一审核）

跑一次「留白 vs 剧透」自检清单（见 `quality-modules.md`），逐条确认：
- 没有提前说「谁是好/坏人」「反派要什么」「情感真相」
- 开场字幕没剧透核心设定
- 片尾金句方向清晰（疑问式留白），没点破底牌答案
- 两层底牌（阴谋层 / 情感层）都还在留白中

这是阶段 B 的**唯一审核**，与全剧收尾冷审不重复。

## 打回规则

- 机械检查不过 → 当场改
- 剧透审查不过 → 定点改对应场次；若发现「浓缩时把底牌带进来了」，回改 B0 的浓缩范围（说明选错了浓缩素材）

## 产出

- 先导片剧本（完整）
- pilot-package（字段见 `references/packages.md`，含钩子清单 + 剧透审查结论）

> 说明：先导片是「独立交付物」，**不产出**定妆单/资产清单/简介单——这三件是「全剧定稿后」的制作层交接物，统一在阶段 C 产出（见 `references/stage-c.md` C5）。先导片阶段的「出场角色/道具」一致性，由「钩子纪律」里的「次要势力简化」兜底，不单独建清单。
