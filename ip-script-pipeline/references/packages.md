# 门禁字段清单（阶段 0 评估报告 + 三个 package）

> 门禁统一原则：**package 必填字段齐全才放行到下一阶段**。以下清单就是门禁的校验依据。

## 阶段 0 评估报告（ip-eval 产出，进阶段 A 前的门禁）

> 阶段 0 是「批量初筛、决定要不要进 A」的关卡，其产出同样要被门禁卡住——评估结论不完整，不进阶段 A。

- [ ] 赛道分流结论 + 语速标准（中文字/秒 vs 英文词/秒 vs 解说 4.5~6.5 字/秒）
- [ ] 题材热度 / 改编适配度 / 平台匹配 / 商业潜力（逐项打点，缺一不可）
- [ ] 投资额分级预判（80万+ / 30–80万 / <30万）
- [ ] 数据画像（追读率 / 付费转化 / 完读率）
- [ ] 「通过 / 不通过」结论（不通过 → 换下一部 IP，不救稿）

> **对标情报门禁**（阶段 0 打点的前置输入，见 `benchmark.md`）：
> - [ ] 对标作品池（3~5 部同题材/同赛道爆款，每部一张卡：作品名/平台/题材/体量/数据信号/采集时间）
> - [ ] 结构拆解表（钩子秒位 / 单集时长 / 付费卡点 / 反转频率 / 情绪节拍 / 开场信息密度，逐部并排 + 共性基准）
> - [ ] 赛道趋势表（题材 × 三赛道热度矩阵 + 生命周期判断 + 建议赛道【附依据】）
> - [ ] 数据基准（可选：采不到标「无公开数据」，用结构拆解兜底）
> - 「题材热度 / 平台匹配 / 商业潜力」三项打点 + 「赛道」分流结论均以对标情报报告为依据，无依据时标「待补情报」。（「改编适配度」为文本判断，不依赖情报。）

> **赛道专属门禁**（按阶段 0 确定的赛道补对应字段）：
> - 选 ② 海外剧：补「语言风格合同（语域/口吻/称呼体系/脏话上限）」+「目标海外平台 + 平台节奏」（见 `overseas-adapter.md`）
> - 选 ③ 解说叙事：补「选题定调（主题/类型/时长/受众/语速）」+「考据范围 + 参考来源」（见 `jieshuo-script.md`）
> - 选 ① 国内剧：无需额外字段，走现有六阶段链。

## adaptation-package（阶段 A 产出）

- [ ] 赛道分流结论 + 语速标准
- [ ] 开发圣经（bible：世界观 / 人物定型 / 台词风格 / 平台节奏矩阵 / **底牌分层+揭示节奏表**）
- [ ] 爽点曲线判定（开头即爆 / 中后期才爆）+ 情绪 12 节拍曲线
- [ ] 锚点索引（保留名场面 / 金句定位表）
- [ ] 分集规划表（含**每集揭示进度标注**：本集落在哪层揭示点之前/之后）
- [ ] 逐章改编稿（带来源标记 / 台词类型 / 情绪光影 / 动作链）
- [ ] 来源等级表（每处内容 直用 / 改写 / 新增 标记）
- [ ] 台词七维诊断结论
- [ ] highlights（可直用高光片段）
- [ ] payoffs（爽点 payoff 清单）
- [ ] 分级定档结论（投资额三档 + 备案路径 + AI 标识方案）
- [ ] 数据画像（追读率 / 付费转化 / 完读率）

## pilot-package（阶段 B 产出）

- [ ] 先导片剧本（完整）
- [ ] 钩子清单（每个钩子来源：已验证 / 预测）
- [ ] **剧透审查结论**（逐条核对「留白 vs 剧透自检清单」，确认未提前揭底牌；并对照开发圣经「底牌分层+揭示节奏表」确认各层底牌仍在留白中）
- [ ] 分级定档一致性声明（与 A 阶段一致）

> 说明：先导片是「独立交付物」，不产出定妆单/资产清单/简介单这三件——它们是「全剧定稿后」的制作层交接物，统一在阶段 C 产出（见 series-package）。先导片阶段的「出场角色/道具」一致性，由「钩子纪律」里的「次要势力简化」兜底，不单独建清单。

## series-package（阶段 C 产出）

- [ ] 分集剧本（全集，每集头部带「揭示边界 / 禁词 / 时间轴」注释）
- [ ] **完整剧本（全剧连体整本，C6 合成，供送审/交付）**
- [ ] 分集大纲（回溯 A4 分季切分 + 每集揭示进度）
- [ ] 平台级分级结论（针对目标平台）
- [ ] 合规精审结论
- [ ] 简介单 / 人物定妆单 / 资产清单表

---

## 赛道② 海外剧 package（英文适配后产出）

> 中文剧本走完 A/B/C 后，若赛道为海外剧，追加「英文适配」产出（见 `overseas-adapter.md`）。

- [ ] 语言风格合同（语域 / 口吻 / 称呼体系 / 脏话上限）
- [ ] 英文版剧本（对白已转北美英语，来源标记 / 台词类型 / 情绪光影字段保留）
- [ ] 语速已按「词/秒」重新校验（不是沿用中文字/秒）
- [ ] 文化语境已本地化（典故/称谓/梗已替换，无硬译）
- [ ] 节奏已按海外平台重排（单集时长 / 钩子位置 / 付费卡点）
- [ ] 文化敏感自检通过

## 赛道③ 解说类 package（解说链产出）

> 解说类走独立解说链，不产出人物定妆单/资产清单（见 `jieshuo-script.md`）。

- [ ] 选题定调（主题 / 类型 / 时长 / 受众 / 语速）
- [ ] 旁白稿（VO Script，逐段旁白 + 字数 + 语速校验）
- [ ] 画面提示表（每段素材方向 + 版权标注）
- [ ] 字幕稿（主字幕 + 强调字幕）
- [ ] 考据来源清单（史实 / 数据的参考来源，可回溯）
