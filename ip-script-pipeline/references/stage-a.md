# 阶段 A · 六阶段编剧链（逐步要点）

> 目标：把存量 IP 稳定改编为剧本。每步标注「输入 / 动作 / 产出 / 模型档位」。

## A1 来源登记

- **模型**：便宜模型
- **动作**：记录 IP 来源与原始文本归档路径；确定投资额分级（80万+ / 30–80万 / <30万 → 备案路径）；确定 AI 标识方案
- **产出**：`来源登记卡`（来源 / 定档 / 标识 / 归档路径）

## A2 IP 与角色开发

- **模型**：便宜模型（可迭代粗稿）
- **上下文**：阶段 0 结论 + 前 5 章（不读全文）
- **动作**：
  1. 提取主角 / 反派 / 配角，各写人物小传。**人物卡统一七字段模板**（缺则填「无」，不空着）：
     - **身份 / 性格 / 口头禅 / 动机 / 成长弧线 / 禁忌 / 与主线关系**
     - 「情感暗线」不放在单个人物卡——它是全剧级的，放开发圣经「情感暗线揭示节奏」表
     - 字段名统一，不用「功能」「弧线」「核心矛盾」「金句」等别名替代
  2. **反派养成**：反派必须有独立目标与自洽逻辑，不做工具人（反派「动机」写「成长弧线」填「无」是正常的）
  3. **爽点曲线判定（必填）**：判断「开头即爆」还是「中后期才爆」
     - 开头即爆 → 先导片从开头浓缩钩子
     - 中后期才爆 → 先补整季爽点曲线，先导片从整季卖点反推
  4. 爽点地图：定位原文所有冲突 / 反转 / 钩子点，标注强度与位置
- **产出**：人物小传（七字段统一）+ 爽点地图 + 爽点曲线判定

## A3 开发圣经（bible）★ 全局一致性锚点

- **模型**：贵模型（错一处，B/C 全错）
- **动作**：产出五份，作为后续所有阶段唯一锚点
  1. **世界观设定**：力量体系 / 规则 / 边界
  2. **人物定型**：性格 / 说话方式 / 禁忌 / 口头禅
  3. **台词风格与语速规范**：承接阶段 0 赛道语速标准
  4. **平台节奏矩阵**：目标平台的集长 / 钩子密度 / 付费点位置
  5. **底牌分层 + 揭示节奏表**：把全剧反转拆成「阴谋层 / 情感层」等多层，逐层标注揭示集数 + 前期替代表述，作为防剧透禁词清单的源头（见 `quality-modules.md`）
- **前置校验**：世界观 / 人设 / 语速三件套自洽，且「底牌分层表」已列出各层揭示集数，不自洽不进 A4
- **产出**：`开发圣经.md`（一次性生成，B/C 复用）

## A4 分集规划 ★ 唯一人工确认点

- **模型**：贵模型
- **动作**：
  1. 分季切分建议：整部 IP 如何切多季
  2. 每集钩子点分布 + 付费点卡位
  3. **每集揭示进度标注**：对照「底牌分层+揭示节奏表」，在分集规划里给每集标上「本集落在哪层揭示点之前/之后」，作为后续 A5/C 逐集写作的揭示边界依据（避免每集临时翻节奏表）
  4. 数据分流：有数据 IP → 钩子取已验证爽点；无数据 IP → 标记「未验证爽点」走预测
- **门禁**：人工确认分集规划后，才进入 A5
- **产出**：分集规划表（含每集揭示进度标注）

## A5 改编稿

- **模型**：便宜模型粗写（**台词精修不在 A5 做，留到 C 阶段切集时统一精修**，避免贵模型跑两遍）
- **上下文**：开发圣经 + 当前章 + 前后 2 章（不喂前 10 章）
- **动作**：
  1. 按原文逐章剧本化改写，不重写原文核心情节
  2. 只补过渡段与剧本化描述
  3. 每处内容强制标记来源等级：`直用 / 改写 / 新增`
  4. 台词统一格式（含类型）：`{类型}【角色（语气）："..."】`，类型见 `quality-modules.md`
  5. 场景描述内联「情绪光影提示」（逆光/冷蓝光/暖光等叙事意图，不写技术参数）
  6. 关键动作补「动作链」分镜提示（撬锁/逃生/打斗等，拆解 3–4 个可拍节拍，见 `quality-modules.md`）
  7. 每章写完先跑「钩子密度 + 来源标记」两道机检，不过当场改
- **边界**：**只做逐章改写，不做分集切分**（分集切分是阶段 C 的职责）。改编稿保留原文章节结构，供 C 阶段切集。**台词只求「顺、准、有类型标注」，精修打磨留到 C 阶段**。
- **产出**：逐章改编稿（带来源标记 + 台词类型 + 情绪光影 + 动作链）

## A6 圆桌审核（多视角交叉审，P0 清零）

- **模型**：便宜模型 × 多视角（成本可控）
- **定位**：阶段 A 的唯一审核。审的是「改编稿」本身，不重复后续冷审。
- **视角**：
  1. 忠实度 P0：核心爽点不丢 / 人设不崩 / 原著粉雷点扫描
  2. 内容安全基础红线粗筛（硬红线）
  3. 钩子密度达标 + 情绪 12 节拍曲线校验
  4. 来源等级标记抽样复核（防漏标「新增」）
  5. 台词七维诊断复核 + 台词类型标注复核（关键反转句是否标类型）
  6. **剧透检查**：是否提前揭了正片底牌（真实动机/反派目标/情感真相）——只抛问题不揭答案。**核对依据是开发圣经「底牌分层+揭示节奏表」**：逐层确认「本集是否落在该层揭示集数之前」，之前的集数不得出现该层等义表述，见 `quality-modules.md`「钩子纪律」+「底牌分层」
- **打回环**：不过 → 定点打回对应章；连续 3 章打回 → 升级冷审 / 回改 A4
- **产出**：审校报告 + adaptation-package
