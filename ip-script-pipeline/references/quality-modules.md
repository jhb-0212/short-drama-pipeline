# 质量模块：底牌分层 + 钩子纪律 + 分集硬约束 + 台词七维 + 台词类型 + 情绪光影 + 情绪 12 节拍

## 钩子纪律（先导片 / 剧本核心铁律）

> 来源：首次试跑《跨界追夫》先导片时暴露的「剧透」问题。先导片的职责是**抛问题、制造想看下去的欲望**，不是**揭答案**。

### 三不原则

1. **不剧透底牌**：全剧最大的反转（谁的真实动机、反派真正要什么、情感真相）一律**留白**，留到正片对应集数才翻。先导片只给「女帝为什么追他」「冥枢要什么」这类**问题**，不给答案。
2. **不提前揭设定**：核心悬念（某物件/身份/规则的真实含义）不在开场字幕或旁白里点破，要由角色在情节推进中自然揭示。开场字幕只标「氛围/地点/时间」，不标「这是什么东西」。
3. **不展开次要势力**：观众无背景的次要人物/势力（如追缉官、影卫），先导片里**简化或删去**，只保留一个模糊的「更大威胁」作悬念即可。展开 = 观众看不懂 = 出戏。

### 开场与节奏纪律

> 来源：试跑《跨界追夫》时暴露的「3 秒钩子缺视觉冲击」「信息重复」「台词重复」「弧线断裂」「时长超标」问题。

1. **开场第一秒必须有视觉冲击点**：不能只靠旁白/悬念吊人，要有一个「眼睛先被抓住」的画面——发光之物、动作爆发、奇观。用原文现成的视觉元素（如"泛着不祥又温柔的青"的印），提到最前。
2. **核心设定信息单集只出现一次**：同一设定（如"七日倒计时"）不在 3 分钟内重复点破，后出现时改为「推进新信息」，不重复旧信息。
3. **旁白一句只承载一个信息点**：不在一句旁白里堆「追了一整个世界 + 为印 + 何必等他」三层。旁白越短越有力，一句一个钩子。
4. **不同场次台词不得重复**：跨场检查，同一句台词（尤其"三日之内…寸步不离"这类长句）不能在两场重复出现。
5. **次要人物出场必须闭环**：次要人物（如追缉官）一旦露头，就要在后续给一个极轻的回收（一个剪影、一句"她没有动手"），否则造成"露了个头就消失"的断裂感。要么闭环，要么干脆不让他露头。
6. **先导片时长上限 3 分钟**：场次宁少勿碎（7 场以内），单场不低于 20 秒。节奏拖了就合并相邻场，核心金句可融入前场结尾，不单独占一场。

### 动作链补拍说明

关键动作（撬锁、强吻逃生、破窗、赴险、打斗）不能只写"结果"，要补 `【动作链·xxx】` 分镜级提示，拆解成 3–4 个可拍的动作节拍：

- 例：`【动作链·撬锁】①手背抵门（借力静音）→ ②指尖探锁眼，侧耳听机关 → ③腕部轻旋，锁芯"咔哒" → ④掌心托印，屏息`
- 例：`【动作链·强吻逃生】①格挡 → ②借惯性贴唇（1秒定格）→ ③她指尖僵住（特写）→ ④挣绳破窗`

**纪律**：只在「动作密集、导演需要知道怎么拍」的关键动作加，普通动作不逐条拆（省 token）。这条同时是剧本层 → 制作层（分镜）的衔接接口。

### 付费卡点断点规则

- 断点必须落在**危险最大 + 悬念最大**的矛盾顶点，不是「减负向」的安慰。
- 正确断法：反派下场 + 危机升级 + 主角被逼到二选一 → 黑屏。
- 错误断法：告诉观众「放心，不会有事」「其实不是要他命」——这会**削弱**紧张感。
- 片尾金句方向要**清晰**：用「疑问式留白」把核心矛盾摆成问题（"她追他，究竟是为了拿回一枚印，还是另有图谋？"），不用方向含糊的句子（如"他偷走一枚印，也偷走一个人的命"——"偷命"到底是害她还是绑她，观众抓不准）。注意：疑问式留白也**不得**直接点出底牌答案（如"救他的命"），否则仍是剧透。

### 底牌分层 + 揭示节奏表（A3 开发圣经必填）★ 剧透治理源头

> 来源：试跑《跨界追夫》先导片 + 分集剧本时反复暴露的「剧透不彻底」问题。根治办法不是事后查禁词，而是**在 A3 开发圣经阶段就把「底牌」拆成多层，并为每一层规定「揭示集数」**。这是所有防剧透纪律的源头。

**核心方法：底牌分两层拆**

一部剧的全剧反转，通常不是「一个答案」，而是**两到三层、在不同集数分批翻**。把它们混为一谈，就会在前期就把它说漏。开发圣经必须显式列出：

| 层 | 内容 | 典型揭示集数 | 前期替代表述 |
|---|---|---|---|
| 阴谋层（反派要什么） | 反派/幕后势力的真实目标（如「要命」「要的不是印是人」） | 第一季中后段（约 11 集前后） | "一件会走的货""另有图谋" |
| 情感层（主角要什么） | 情感真相 / 真实动机（如「追的是人」「以身为锚」「救他的命」） | 全剧末段（约 19 集前后） | 同上，更模糊 |

**纪律**：
1. **A3 必须产出「底牌分层 + 揭示节奏表」**，作为 `开发圣经.md` 的固定一节，列明：每层底牌是什么、在哪个集数翻、翻之前用什么模糊表述替代。
2. **禁词清单由这张表反推**：每一层底牌在「揭示集数」之前出现的所有等义表述，全部进禁词清单。禁词不是拍脑袋列的，是从底牌分层表倒推出来的。
3. **分集剧本严格对照这张表**：写作前先查本集在第几层揭示点之前/之后，决定本集能用多明确的表述。写错集数的表述 → 打回。**执行落地**：A4 分集规划已把「每集落在哪层揭示点之前/之后」标注好，A5/C 逐集写作时直接读 A4 标注；这张分层表是 A3/A4 生成标注的源头，逐集写作阶段不必再逐集重查表。
4. **跨季也要重新分层**：进入第二季，若有新底牌（如新时空的真相），同样先在开发圣经补一张分层表，再动笔。

**「观察」与「推论」的边界（防半揭越界）**：

> 来源：试跑《跨界追夫》第 10 集暴露——鹤惊霜一句「要拿莲台活炼一个人」看似只是"观察"，实则**已经推论出了「冥枢要命」**，把阴谋层底牌提前漏了。教训：半揭节点最容易在「观察」时顺带「推论」，越界而不自知。

- **观察**（安全）：只描述角色**看到/感知到的事实**——「莲台是活的」「纹路在搏动」「莲台认血」。这些不揭示底牌，合规。
- **推论**（越界）：把观察到的事实**归纳成结论**——「要活炼一个人」「要的不是印是命」「她护他是因为他是锚命之人」。这些等于点破底牌，在揭示集数之前禁用。
- **事实 vs 动机**（尤其针对阴谋层底牌）：反派底牌往往由「动机」构成（冥枢「要命」= 要拿主角填莲台）。半揭时可以**只揭事实、不揭动机**——「江渡被冥枢灭门」「冥枢当年看过他一眼」「他在等」，这些都是**事实**；但「要把他填进莲台/养成棋子」是**动机**，揭示集数之前禁用。**「养棋」「等他长大」这类词本身也在暗示动机，同样要收敛**。
- **纪律**：半揭节点（如第 7 集「你重要」、第 10 集「不只是为印」）的台词，**只写观察、不写推论**；涉及反派阴谋时，**只揭事实、不揭动机**。检查时逐句问：「这句是角色看到的，还是角色推断出的结论？是事实，还是动机？」推论句、动机句一律删改或退回模糊观察。
- **自查标注要写清**：「未推论要命」而不是「未直接点破要命」——「直接点破」和「推论点破」都要禁，两者都会越界。同理「未揭动机」比「未揭阴谋」更精确。

### 分集剧本专项纪律（六条硬约束）

> 来源：试跑《跨界追夫》分集剧本时暴露的「防剧透不彻底、时间线跳日、锚认主表述违规、动作链缺步」问题。这六条是**逐集必过的硬门槛**，缺一即打回。其中「防剧透纪律」的禁词清单，必须由上面「底牌分层 + 揭示节奏表」倒推而来，而非零散列举。

1. **防剧透纪律（禁词清单）**：分集前期（尤其免费的前 3 集）**严禁出现**任何「底牌分层表」中尚未到揭示集数的字样或等义表述（如 `锚命之人`、`要命`、`追的是人`、`以身为锚`、`救他的命`）。前期一律用分层表里的模糊表述替代。**禁词清单必须以开发圣经「底牌分层 + 揭示节奏表」为准**，每换一部 IP 都要重列，不套用上部的禁词。
2. **时间线一致性**：每集结尾的倒计时字幕，必须与全局时间轴对齐（`第0夜偷印 → 第1日 → … → 第7日交叠`），**不跳日、不倒序、不自相矛盾**。写作前先对照分集规划确认本集对应第几日，结尾字幕只标本集推进到的时间点。**字幕统一「第N日 + 还剩M天」双写**（如"第一日，还剩六天"）。**一天可跨两集**（短剧正常节奏）：跨集的第二集结尾仍写同一天的字幕，不强行推进。
   - **标题也不得剧透**：每集标题同样受「防剧透 + 时间线」约束。标题不能提前点破本集尚未揭示的设定（如「两界交叠」若属底牌/核心设定，标题应改成只标进度的「倒计时」）。标题信息 ≤ 本集揭示进度。
   - **规范表与剧本同步更新**：开发圣经里的「字幕规范表（对应集）」是**活文档**，一旦分集规划调整了某集内容/天数，规范表的「对应集」列必须同步更新，否则后续复用会照着过时表写出错位。
3. **锚认主细则**：认主是递进关系——`碰过留气 → 护过才认主`。**记气 ≠ 认主**。前期只能说「沾了你的气」「留了气」，**不得说「认了你」「认我」**，直到剧情走到「护」的节点（如天台救他）才可升级为「认主」。
4. **钩子纪律**：每集只推进**一个 D 节点**，结尾断在悬念顶点；**不重复上一集已用过的钩子**（跨集查重）。
5. **动作链完整性**：每个逃生/反杀动作必须有 `触发 → 动作 → 结果` 三步闭环。**不出现无铺垫的「挣断绳索」**——要先有「他被缚、如何借力、为何能挣断」的触发交代（如"袖中灵索缠上双腕"→"挣断灵索"）。**束缚类道具一旦在前场出现，后场挣脱时名字必须一致**。
6. **台词七维**：关键句保留金句气口；**旁白单场 ≤ 25 字**（约 10 秒）；**画外音只补新信息，不重复前场整句**。

**配套细则（同源硬约束）**：
- **道具来源一致**：角色没有的东西不能凭空出现（如仙界来的女主，不能"掏出碎屏旧手机"——应是"接过路人递来的手机"）。
- **信息来源一致**：角色不能说出他前几集还没获得的信息（如没听过"冥枢"这个名字，就不能直呼其名，改说"那些追印的人"）。
- **旁白不得说角色不知的信息**：旁白是第三方，但也不能剧透底牌/隐藏动机（如不能说"他被挑中的锚命之人"）。
- **次要人物退场要交代**：角色离场要有明确的动作/台词收尾（如"我先挡，你带他走"），不能喊完一句就凭空消失。

### 留白 vs 剧透的自检清单

写完后逐条问：
- [ ] 有没有把「谁其实是好人/坏人」提前说了？
- [ ] 有没有把「反派真正要的东西」提前说了？
- [ ] 有没有把「情感真相（她/他其实…）」提前说了？
- [ ] 开场字幕有没有剧透核心设定？
- [ ] 付费卡点是不是断在「危险+悬念」顶点，而不是「安慰」？
- [ ] 开场第一秒有没有「视觉冲击点」（发光/动作/奇观），还是只靠旁白吊人？
- [ ] 核心设定有没有在同一集内重复点破？
- [ ] 旁白有没有一句堆多个信息点？
- [ ] 同一句台词有没有在不同场次重复出现？
- [ ] 露了头的次要人物，后续有没有回收（闭环）？
- [ ] 片尾金句方向是否清晰（疑问式留白），有没有方向含糊？
- [ ] 先导片时长是否 ≤ 3 分钟、场次 ≤ 7？
- [ ] 前 3 集有没有出现禁词（锚命之人/要命/追的是人/以身为锚/救他的命）？
- [ ] 禁词清单是否由开发圣经「底牌分层+揭示节奏表」倒推而来（而非拍脑袋列举）？
- [ ] 本集揭示进度是否落在分层表规定的集数之后（有没有在「阴谋层/情感层」揭示点之前就用了过明确的表述）？
- [ ] 半揭节点（如「你重要」「不只是为印」）的台词，是**只写观察**还是**顺带做了推论**（「要炼一个人」「要命」等结论句）？推论句是否已删改？
- [ ] 本集倒计时字幕是否与全局时间轴对齐，无跳日/倒序/矛盾？
- [ ] 本集标题有没有提前点破设定/底牌（标题信息是否 ≤ 本集揭示进度）？
- [ ] 锚认主表述是否合规（前期只说「留气」，不说「认了你」）？
- [ ] 本集是否只推进一个 D 节点，钩子有没有跨集重复？
- [ ] 每个逃生/反杀动作有没有「触发→动作→结果」三步，有无无铺垫的「挣断绳索」？
- [ ] 旁白单场是否 ≤ 25 字，画外音有没有重复前场整句？
- [ ] 道具来源是否一致（角色没有的东西有没有凭空出现）？
- [ ] 信息来源是否一致（角色有没有说出他前几集还没获得的信息/名字）？
- [ ] 旁白有没有说出角色当下不知道的信息（含底牌、隐藏动机）？
- [ ] 次要人物离场有没有明确交代（还是喊完一句就消失）？



## 台词类型（A5 必标维度）

每句台词必须显式标注类型。类型决定语速、情绪节拍与镜头衔接，不能留到分镜阶段猜：

| 类型 | 用途 | 短剧高频场景 |
|---|---|---|
| 对白 | 角色间对话 | 主线推进 |
| 独白 | 角色自说自话 | 内心挣扎、自我说服 |
| 旁白 | 第三方叙事声 | 世界观揭示、转场衔接 |
| 心声 | 角色内心 OS（观众可见） | 反差笑点、口是心非、甜宠 |
| 画外音 | 画面外声音（人物/音效） | 电话、回忆、蒙太奇 |
| 字幕 | 屏幕文字 | 时间倒计时、地点、悬念断点 |

**统一格式（扩展版）**：`{类型}【角色（语气）："..."】`，全流程必写。例：`心声【女帝（傲娇）："本座……才不是追他。"】`

**执行纪律**：每集关键反转句（尤其心声/旁白/字幕）必须标类型；普通对白可用 `对白` 简标或省略（省 token）。

## 情绪光影提示（场景描述内联，轻量）

场景描述中可用**叙事性光影提示**表达画面情绪意图（非技术打光参数）。技术性打光/构图参数属制作层，不写进剧本。

- 例：`（逆光，剪影）女帝从莲台走下` —— 营造气场
- 例：`（冷蓝光）冥枢裂缝浮现` —— 营造危机感
- 例：`（暖黄烛光）夜市重逢` —— 营造甜宠氛围

**纪律**：只在「需要引导情绪」的场景加，普通场景不加，避免剧本臃肿。

## 台词七维诊断

对每句台词检查七个维度，逐维打分（0–10）并给修改建议：

1. **信息量**：是否推进剧情 / 揭示信息，还是纯口水
2. **情绪强度**：情绪浓度是否匹配场景，是否过平或过满
3. **人设贴合**：是否像这个角色说的话（对照开发圣经的人物定型）
4. **语速适配**：句长是否符合赛道语速标准（对照阶段 0 语速）
5. **金句发酵气口**：关键台词是否留出「被记住 / 被转发」的停顿
6. **超长句拆镜**：超过语速上限的长句是否拆分或拆镜
7. **口语化自然度**：书面语是否转成自然对话

**执行纪律**：只对「每集前 3 句 + 关键转折句」做七维精检，不逐句跑（省成本）。

**统一格式**：`台词：【角色（语气）："..."】`，全流程必写。

## 情绪 12 节拍曲线

对整片/整集的张力做 0~10 量化，画出折线图脚本，校验：

1. **波峰 / 波谷分布**：张力曲线是否有节奏起伏，不一条平线
2. **第 9 拍反杀峰值校验**：结局前必须有一个反转峰值（约第 9 拍），是全片张力最高点或次高点
3. **开头钩子**：第 1 拍张力需足够高以抓人
