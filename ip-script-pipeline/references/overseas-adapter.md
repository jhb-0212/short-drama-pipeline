# 赛道② · 海外剧英文对白适配层

> 定位：海外剧出海**不是**「另写一套英文编剧链」，而是**复用现有六阶段链（中文写）→ 加一层「英文对白适配」**。剧本骨架、爽点、分集结构全是现成的，本层只解决「中文对白怎么变成地道、能投流的北美英语」。
> 原则：**中文是「内容真源」，英文是「适配产物」**。改英文不改剧情，改表达不改人设。

---

## 一、为什么「中文写 → 英文适配」，而不是「直接英文写」

| 方式 | 优点 | 缺点 |
|---|---|---|
| 中文写 → 英文适配（本层采用） | 复用全部现有六阶段链 + 开发圣经 + 防剧透纪律；中文世界观/人设/节奏成熟 | 多一道适配工序 |
| 直接英文写 | 无翻译损耗 | 要另建英文编剧链、英文开发圣经，成本翻倍且难复用 |

**结论**：对「把已验证的国内爆款短剧出海」这个主场景，中文先写、再适配是性价比最高的路。若将来做「原生英文原创」，再单独建链，不在本层。

---

## 二、适配四步（中文剧本定稿后执行）

```
中文剧本定稿（走完 A/B/C）
   → ① 语言风格合同（定英文对白的语域/口吻）
   → ② 逐句对白转译（中文→北美英语，见「转译纪律」）
   → ③ 文化语境替换（典故/称谓/梗 → 英文语境等价物）
   → ④ 海外节奏重排（词/秒语速 + 海外平台节奏）
```

### ① 语言风格合同（Language & Style Contract）

开译前先定一份「语言风格合同」，锁定英文对白的语域与口吻，全片统一（对应国内剧的「开发圣经·台词风格」）：

| 维度 | 选项 | 说明 |
|---|---|---|
| 语域（register） | 正式 / 口语 / 俚语化 | 短剧默认**口语化、简短、有情绪**，避免书面腔 |
| 口吻（tone） | 冷峻 / 甜宠 / 爽燃 / 悬疑 | 随剧种定，全片统一 |
| 称呼体系 | 名字直呼 / 敬称 / 昵称 | 中文「沈总/梁爷」→ 英文按关系转（见③） |
| 脏话/语气词上限 | 每集 N 次 | 海外短剧可适度口语化，但要卡上限防脏 |

> 这份合同是英文适配的「开发圣经」，一次定好，逐集复用，不逐集漂移。

### ② 逐句对白转译纪律（中文 → 北美英语）

**核心：译「意」不译「字」，译「情绪」不译「字面」。**

| 错误译法（直译） | 正确译法（意译） |
|---|---|
| 「手艺人，不问来路」→ "A craftsman doesn't ask where it comes from."（生硬） | "A thief never asks where the goods came from."（贴人设） |
| 「货到了，债就清了」→ "When the goods arrive, the debt is clear."（书面） | "One delivery, and we're square."（口语、有力度） |
| 「你盗的不是货，是锚」→ "What you stole isn't goods, it's an anchor."（词对词） | "You didn't steal goods. You stole the anchor."（节奏、强调） |

**三条转译铁律**：
1. **拆长句**：中文对白常一句多意，英文要拆成短句（英文短剧单句更短、更有冲击）。
2. **去中文腔**：删「的/了/吧/呢」对应的英文冗余（"just", "actually", "you know" 泛滥是中式英文重灾区）。
3. **贴人设口吻**：英文对白必须像「这个角色」说出来的——冷峻反派用短句少形容词，甜宠主角用情绪词多。

**语速转换**：中文 4.5~6.5 字/秒 → 英文 **2.0~2.8 词/秒**（英文词比中文字长，同样时长能容纳的词数少）。校验公式从「字数÷语速」换成「词数÷词速」。

### ③ 文化语境替换（Cultural Localization）

中文语境里的东西，直译成英文会「看不懂」或「出戏」，要换成英文语境的等价物：

| 中文原项 | 直译（错） | 本地化（对） |
|---|---|---|
| 称呼「沈总」「梁爷」 | "President Shen", "Master Liang" | 按关系转："Ms. Shen" / "Old Liang" 或昵称 |
| 典故「两界」「修仙」「命格」 | 直译修仙术语（老外无感） | 映射到海外观众熟知的「魔法/异能/宿命」体系 |
| 梗「内卷」「凡尔赛」 | 直译梗（无人懂） | 换成英文等价梗，或直接删改成本地幽默 |
| 计量「斤两」「时辰」 | 直译单位 | 换成磅/小时等英文习惯单位 |

**纪律**：
- **不硬译专有名词**：人名、地名用拼音（Shen Qingwu / Liang Da）保留，但给英文观众「能念」的拼写。
- **修仙/玄幻体系**：映射到「魔法/异能/超自然」的英文短剧成熟表达，不逐字译「灵力/金丹」这类术语。
- **删梗不硬翻**：中文梗没有英文等价物时，**删掉或改写**，不硬塞一个「半懂不懂」的直译梗。

### ④ 海外节奏重排（词/秒 + 平台节奏）

海外短剧（ReelShort / DramaBox / GoodShort 等）节奏和国内短剧**不同**：

| 维度 | 国内短剧 | 海外短剧 |
|---|---|---|
| 单集时长 | 1~3 分钟 | 1~2 分钟（更短） |
| 语速 | 4.5~6.5 字/秒 | 2.0~2.8 词/秒 |
| 钩子节奏 | 前 3 秒钩子 | 前 1~2 秒钩子（更狠） |
| 台词密度 | 中等 | 更低（画面叙事更多，英文对白更省） |

**纪律**：
- 中文剧本的「分集规划」在英文适配时**要重排节奏**：单集更短、钩子更靠前、台词更省。
- 英文短剧**更依赖画面+表情**，对白只是辅助——中文里靠台词交代的信息，英文版要更多转成画面动作。
- 付费卡点位置随平台调（海外平台的付费点节奏和国内不同，参考目标平台的分集规范）。

---

## 三、交付物（英文适配后）

中文剧本适配后，产出**英文版剧本**（English Script），字段和中文版对齐，但：
- 对白换成北美英语（带风格合同约定的口吻）
- 语速标准换成「词/秒」并已校验
- 文化语境已本地化
- 节奏已按海外平台重排

> 英文版剧本仍保留「来源标记 / 台词类型 / 情绪光影」等中文版的字段，只是语言换了。**中文版是存档真源，英文版是投流产物，两者并存。**

---

## 四、边界与免责

1. **不承诺「翻译等于原生」**：适配是「地道化」，不是「达到母语编剧水平」。若要求原生级英文，需英文母语编剧润色（本层可出稿后交给母语审校）。
2. **版权注意**：出海涉及海外平台版权协议，本层只解决「剧本语言」，不碰「版权/发行」。
3. **文化敏感**：某些中文梗/表达在英文语境可能冒犯或误解，适配时要过一道「文化敏感自检」（见下）。

### 文化敏感自检（英文适配后必过）
- [ ] 有没有中文里正常、英文里冒犯的称呼/表达？
- [ ] 有没有英文观众看不懂的典故/术语没替换？
- [ ] 有没有「中式英文」的冗余词（just/actually/you know 泛滥）？
- [ ] 语速是否已按「词/秒」重新校验（不是沿用中文字/秒）？
- [ ] 单集时长/钩子节奏是否已按海外平台重排？
