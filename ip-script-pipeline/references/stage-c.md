# 阶段 C · 分集剧本制作（逐步要点）

> 目标：把 A 阶段的「改编稿」按 A4 分集规划切成逐集剧本。核心纪律是**每一集开写前，先读 A4 分集规划表里本集的「揭示进度标注」锁定本集揭示边界**，再动笔。这是「分集剧本按节奏表走」的硬前提。

## C0 开写前准备（每集必做，先于写作）

每写一集，先完成下面三步，缺一不写。**揭示边界以 A4 分集规划表的「每集揭示进度标注」为准，不重新查开发圣经推一遍**（避免两处结论不一致）：

1. **读本集揭示进度**：直接读 A4 分集规划表里本集的「揭示进度标注」（落在哪层揭示点之前/之后），写成「本集可揭示边界」一句话，例如：`第4集：阴谋层/情感层均未翻，只能用模糊表述（一件会走的货/另有图谋），禁词全部禁用`。
2. **锁禁词清单**：从 A3 已定型的「底牌分层表 + 禁词清单」（复用件）中，取「本集揭示进度之前尚未翻的层」对应的等义表述，逐条列出。**不重新倒推**——禁词清单 A3 已生成，直接引用。
3. **对时间轴**：确认本集对应全局时间轴的第几日，结尾字幕该写什么（「第N日 + 还剩M天」双写）。

这三步的产出，写进本集稿件的开头注释（`<!-- 揭示边界 / 禁词 / 时间轴 -->`），供后续机械检查直接读取。若发现 A4 标注与本集实际剧情冲突，**回改 A4 而非就地改 C0**。

## C1 逐集写作（模型分层）

> 输入是 A 阶段的「改编稿」（逐章）+ A4「分集规划」（分季切分 + 每集揭示进度）。把改编稿的章节内容按分集规划**切成逐集**，每集 1.5–2 分钟。

- **粗写**：便宜模型，把改编稿对应章节切成单集正文
- **台词精修**：贵模型，只对本集「前 3 句 + 关键转折句」做七维精修
- **写作时同步执行六条硬约束**（防剧透 / 时间线 / 锚认主 / 钩子 / 动作链 / 台词七维），逐条对照，见 `quality-modules.md`「分集剧本专项纪律」

## C2 机械检查（每集写完即跑，先于模型审核）

写完一集，**立即跑机械检查**，不进下一集：

- Grep 搜本集禁词清单 → 出现即打回
- Grep 搜跨集钩子关键词 → 与上一集重复即打回
- 抽本集倒计时字幕 → 核对时间轴无跳日/倒序
- 抽本集标题 → 核对信息 ≤ 本集揭示进度（标题不剧透）

清掉机械问题后，才进入语义审核。机械检查能拦下 60% 以上低级错误，见 `economy.md`。

## C3 平台级分级 + 合规精审

- 平台级分级：针对目标平台的集长 / 钩子密度 / 付费点复核
- 合规精审：内容安全红线 + 来源等级标记复核

## C4 轻量一致性审查（阶段 C 的唯一审核）

- 换模型交叉审：用与生产不同的模型，重点挑「语义级剧透」——是否在揭示点之前用了过明确的表述（机械检查查不出的「换一种说法」的剧透）
- 隔天回看：次日回看本集，复核揭示节奏与情感弧线
- **注意**：这是阶段 C 的轻量审查，聚焦「本阶段产出的逐集一致性」。全剧跨阶段贯通后的交叉一致性，留给「全剧收尾冷审」统一做，不在这里重复。

## 打回规则

- 机械检查不过 → 当场改本集
- 语义剧透不过 → 定点打回本集
- 连续 3 集在「揭示边界」上出问题 → 回改 A4 分集规划的「每集揭示进度标注」；若判定是底牌分层表本身设错了揭示集数，则回改 A3 开发圣经「底牌分层+揭示节奏表」

## C5 产出配套件（简介单 / 人物定妆单 / 资产清单）

> 这三件是剧本层 → 制作层（分镜/成片）的**标准接口**，在阶段 C 收尾时一并产出，作为 series-package 的一部分。它们是「从剧本里提取」的结构化清单，不是另写新内容。**字段与铁律以 `references/make-spec.md` 为准**，不在这里另编字段。

1. **简介单**：片名/类型/题材/总时长/幕数/镜头数/画幅/风格/色调/参考作品/目标受众/用途 + 150–300 字剧情梗概 + 分幕结构表 + 风格视听定调 + 主创交付（见 make-spec「剧本简介单」）。
2. **人物定妆单**：每个有台词/正脸/戏份的人物一行，14 个字段全填（姓名/身份/年龄/性别/身高体型/脸型五官/发型发色/皮肤质感/服装造型/性格关键词/行为习惯/说话方式/人物关系/情绪基调/参考图），遵守三大铁律（一人一版不换脸/面部干净/群演各不相同）（见 make-spec「人物定妆单」）。
3. **资产清单表**：人物清单 + 场景清单 + 道具清单 + 声音资产四张子表，编号化，标注出场镜头数/时长/资产要求（三视图 vs 单体图、四面图 vs 单面图）（见 make-spec「资产清单表」）。

**纪律**：这三件是「提取」不是「创作」——所有内容必须能在开发圣经或剧本里找到出处，不新造设定。若提取时发现剧本里某道具/角色外貌前后矛盾，回改对应集，而非在清单里硬统一。

## C6 全集合成完整剧本（逐集 → 连体整本）

> 逐集剧本是「按集交付」的成品，但送审/整体交付（如交给合规审查、平台投稿、制作组通读）时需要**一份连成一体的完整剧本**。C6 就是把逐集稿合并成整本，**只做格式统一与排序，不改写任何一集的正文**。

1. **合并顺序**：按 A4 分集规划的集序，把逐集正文依序拼接，每集以「第N集 + 标题」为一级标题分隔。
2. **格式统一**：全剧统一的扉页（剧名/类型/总集数/单集时长/编剧/日期）+ 统一台词格式（`{类型}【角色（语气）："..."】`）+ 统一字幕格式。**不逐集重排正文，只对齐格式**。
3. **保留头部注释**：每集开头保留「揭示边界 / 禁词 / 时间轴」注释（作为分集写作依据留档），或在卷首集中列一张「全集揭示进度总表」替代逐集注释（二选一，供后续机械检查/复查引用）。
4. **机械核验**（合成后即跑）：Grep 核对集序连续（第1…N集无缺号/跳号）、跨集无重复钩子、时间轴字幕全程连贯、禁词未在揭示集数前出现。
5. **冷审入口**：完整剧本是「全剧收尾冷审」的**唯一审查对象**——冷审通读整本、换模型交叉审、隔天回看，均针对这份连体完整剧本，而非逐集散稿。

**产出**：`完整剧本.md`（全剧连体整本，供送审/交付）+ 逐集剧本稿（保留散文件，供逐集修改）。

## 产出

- 逐集剧本稿（每集头部带「揭示边界 / 禁词 / 时间轴」注释）
- **完整剧本（全剧连体整本，C6 合成）**
- series-package（字段见 `references/packages.md`，含完整剧本 + 简介单 / 人物定妆单 / 资产清单）
