# 赛道③ · 解说叙事剧本链（旁白稿 VO Script）

> 定位：解说类内容**不是**「分集对白剧本」，而是「**旁白稿 VO Script + 画面素材匹配**」。它没有角色对白、没有站位轴线，核心是「一段能配画面、能听懂、能留住人的旁白」。**不套用六阶段编剧链**，走独立的解说链。
> 适用：历史人物志 / 事件战役 / 科普知识 三类解说短视频/中视频。

---

## 一、为什么解说类要走独立链，不套六阶段编剧链

| 维度 | 国内短剧（对白剧本） | 解说类（旁白稿） |
|---|---|---|
| 核心载体 | 角色对白 | 第三方旁白（VO） |
| 叙事主体 | 人物对话推进 | 旁白单口推进 |
| 结构 | 分集 + 钩子 + 付费卡点 | 单条成片，起承转合 |
| 语速 | 4.5~6.5 字/秒（对白） | **4.5~6.5 字/秒（旁白，稍慢更稳）** |
| 产物 | 分集剧本 | **旁白稿 + 画面分镜提示 + 字幕** |

**结论**：解说类的「剧本」就是「旁白稿」，没有 A1~A6 那套（角色开发/台词七维/圆桌审核都用不上）。它有自己的「选题 → 考据 → 结构 → 旁白 → 画面匹配」五步。

---

## 二、解说链五步

```
① 选题定调 → ② 史料/事实考据 → ③ 结构骨架 → ④ 旁白稿撰写 → ⑤ 画面匹配 + 字幕
```

### ① 选题定调（这条片子讲什么、给谁看、多长）

| 项 | 说明 |
|---|---|
| 主题 | 一句话说清「这条片子的核心命题」 |
| 类型 | 历史人物志 / 事件战役 / 科普知识 |
| 时长 | 30s / 60s / 3min / 5min（决定旁白字数） |
| 受众 | 泛大众 / 垂直兴趣（决定讲多深） |
| 语速 | 默认 5 字/秒（解说稍慢更稳，4.5~6.5 区间） |

**字数预算**：时长 × 语速 = 旁白总字数。例：3 分钟 × 5 字/秒 = 900 字。**先算字数再写，防止写超时长。**

### ② 史料/事实考据（历史类必做，科普类必核）

历史解说**必须考据**，科普解说**必须核事实**，这是解说的生命线（说错 = 翻车）。

| 类型 | 考据要求 |
|---|---|
| 历史人物志 | 生平时间线 / 关键事件 / 争议点，**多源交叉核对**（正史+研究+实物），不编造对话细节 |
| 事件战役 | 时间/地点/双方/过程/结果，**战场时序不颠倒**，数字有出处 |
| 科普知识 | 原理/数据/出处，**数据标来源**，不传播伪科学 |

**纪律**：
- 历史类「**有据可查的讲事实，无据的明确说'史界有争议'**」，不把野史当正史、不把演义当史实。
- 科普类「**不确定的标注'目前认为'**」，不把假说讲成定论。
- 引用数字/日期**必须可回溯**，写进稿尾「参考来源」。

### ③ 结构骨架（起承转合，钩子在前）

解说稿的结构和短剧一样要「钩子」，但钩子是「**悬念/反常识/冲突**」而不是「人物悬念」：

```
【钩子】前 3 秒抛出「反常识/悬念/冲突」（例："他活了 83 岁，却只被记住最后 10 秒。"）
【背景】交代必要背景，最短篇幅
【主体】按时间线/逻辑线推进，每段一个信息点
【高潮】矛盾最集中/结论最颠覆的点
【落点】收束，留一句「金句」或「开放性思考」
```

**纪律**：
- **一段一个信息点**：旁白不堆信息，一段讲清一件事再讲下一件。
- **金句落点**：结尾留一句「能被截图转发」的金句（对应短剧的「金句气口」）。
- **不剧透式拖沓**：解说也要「每一句都推进」，不注水、不绕圈。

### ④ 旁白稿撰写（VO Script）

旁白稿是解说链的**核心产物**，格式和「台词」不同——它是**第三人称叙事口吻**，不是角色对白：

```
【旁白】"……"（标字数，校验语速）
```

**撰写纪律**：
1. **口语化**：像「一个人在跟你讲」，不是「念论文」。书面语转口语（"因此"→"所以"，"其"→"它"）。
2. **短句**：旁白单句更短，好断句、好配画面。长句拆短。
3. **有节奏**：快慢交替，关键处留气口（停顿），不是匀速念稿。
4. **去 AI 腔**：不用「首先/其次/最后」的模板腔，不堆「众所周知」，直接进入正题。
5. **旁白不抢戏**：旁白是「配画面」的，不是「念全文」——画面能表达的，旁白少说。

**语速校验**：`旁白字数 ÷ 语速(4.5~6.5) ≤ 时长`。超了删词或加时长，和解说类「字数预算」对齐。

### ⑤ 画面匹配 + 字幕

解说稿不是「纯文字」，它要能「配画面」。每个旁白段落标注**画面提示**（用什么素材/画面）：

| 段落 | 旁白 | 画面提示 | 字幕 |
|---|---|---|---|
| 钩子 | "他活了 83 岁，却只被记住最后 10 秒。" | 老照片/画像 + 定格 | 主字幕 + 强调字 |
| 背景 | "……" | 史料影像/地图 | 说明字幕 |
| 主体 | "……" | 时间线动画/实物图 | 关键词字幕 |

**纪律**：
- **画面提示是「找素材的方向」，不是「分镜」**——解说类的画面是「素材匹配」，不是「镜头调度」，不做站位/轴线/运镜那套（那是制作层分镜的事）。
- **字幕分主字幕 + 强调字幕**：主字幕是旁白全文，强调字幕是关键数字/金句的「放大定格」。
- **版权**：历史影像/图片有版权，画面提示里标注「需授权素材」或「可用公共领域素材」。

---

## 三、两类解说的差异

| 维度 | 历史人物志 | 事件战役 | 科普知识 |
|---|---|---|---|
| 钩子 | 反常识/命运反差 | 悬念/胜负悬念 | 反常识/颠覆认知 |
| 考据重点 | 生平真实性 | 时序/数字准确性 | 原理正确性 |
| 主体推进 | 时间线（生平） | 时序（战役过程） | 逻辑线（是什么→为什么→怎么用） |
| 落点 | 人物评价/启示 | 胜负原因/影响 | 认知升级/实用结论 |
| 情绪 | 唏嘘/敬仰 | 紧张/壮烈 | 好奇/恍然大悟 |

---

## 四、交付物（解说链产出）

解说链产出的不是「分集剧本」，而是**解说稿 package**：

- **旁白稿（VO Script）**：逐段旁白 + 字数 + 语速校验
- **画面提示表**：每段对应的素材方向 + 版权标注
- **字幕稿**：主字幕 + 强调字幕
- **考据来源**：史实/数据的参考来源清单

> 解说稿 package 是「独立交付物」，**不产出人物定妆单/资产清单**（解说类没有角色资产）。它和制作层的「分镜」关系也不同——解说类直接进「素材剪辑」，不需要分镜表/七段式提示词那套。
>
> **成片承接**：解说稿 package 产出后，转 `ip-jieshuo-pipeline`（解说成片流水线）——它消费本 package，产出素材匹配表 + 成片提示词 + 字幕 SRT + 离线解说看板。**不是** `ip-make-pipeline`（那是分镜流水线，不适用解说类）。

---

## 五、边界

1. **不混用**：解说链和六阶段编剧链是**两条平行线**，不要拿「台词七维」去审旁白稿（旁白是叙事口吻，不是角色对白），也不要拿「解说结构」去套分集剧本。
2. **考据是底线**：历史/科普解说说错了是硬伤，宁可不讲，不讲错。无据的明确标注「有争议」。
3. **版权**：解说类大量用史料影像/图片，版权风险集中在「素材」，画面提示里必须标注来源与授权状态。
