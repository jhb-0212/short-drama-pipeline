# ip-script-pipeline · 短剧「IP → 剧本」剧本层流水线

一套**规则库驱动的剧本改编 skill**，把存量网文 IP 稳定改编成「能过审、可直接用」的短剧/剧集剧本。核心是六阶段编剧链 + 赛道硬分流 + 经济性设计，产出的人物定妆单 + 简介单 + 资产清单（`make-spec.md`）作为衔接制作层的标准接口。

> 配套下游：`ip-make-pipeline`（制作层·分镜成片）、`ip-jieshuo-pipeline`（解说成片）。本 skill 只负责「讲什么」，不管「怎么拍」。

---

## 一句话定位

**用「开发圣经」保证跨集一致性，用「机械检查优先」保证经济实惠，用「赛道硬分流」保证规则不串味。**

---

## 三大核心设计

| 设计 | 含义 | 靠什么兑现 |
|---|---|---|
| **跨集一致性** | 角色/世界观/底牌节奏全局唯一，不逐集漂移 | 开发圣经（A3）+ 底牌分层揭示节奏表 + 复用件只生成一次 |
| **经济实惠** | 便宜模型干粗活、贵模型干细活，上下文不重复加载 | 模型分层表 + 上下文隔离清单（`economy.md`） |
| **机械检查优先** | 检索/对比类错误先用 Grep 机械查，清掉低级错再进模型 | 跨集查重 / 禁词 / 时间线 / 人名道具一致性 |

---

## 能解决什么问题

| 翻车 | 对应防线 |
|---|---|
| 小说直接当剧本用，没过审风险 | 六阶段编剧链 + 合规精审 + 冷审 |
| 第 1 集和第 10 集角色性格漂移 | 开发圣经 + 人物小传复用件 |
| 底牌过早泄露，钩子失效 | 底牌分层 + 揭示节奏表 + 钩子纪律（三不原则） |
| 每阶段重复喂全文，调用成本爆炸 | 上下文隔离 + 复用件只生成一次 |
| 拿国内剧规则硬套海外剧/解说 | 🔒 赛道硬分流（阶段 0 必做） |

---

## 赛道分流（阶段 0 硬开关）

| 赛道 | 规则链 | 语速标准 | 规则入口 |
|---|---|---|---|
| ① 国内剧 | 六阶段编剧链 + B 先导片 + C 分集 | 中文 4.5~6.5 字/秒 | 本文件 |
| ② 海外剧 | 六阶段链（中文写）→ 英文对白适配层 | 英文 2.0~2.8 词/秒 | `references/overseas-adapter.md` |
| ③ 解说叙事 | 解说剧本链（旁白稿 VO Script） | 解说 4.5~6.5 字/秒 | `references/jieshuo-script.md` |

赛道不是「写完再补的标签」，是决定走哪条规则链的**硬开关**。未定赛道不进场。

---

## 流程总览

```
阶段 0  ip-eval         IP 池筛选 + 赛道分流
阶段 A  六阶段编剧链     来源登记→角色开发→开发圣经→分集规划→改编稿→圆桌审核
阶段 B  novel-to-pilot  浓缩成先导片剧本
阶段 C  pilot-to-series 扩展成分集剧本
冷审     全剧收尾         机械检查 → 换模型交叉审 → 隔天回看（统一一次）
```

- **A 产出「改编稿」**：逐章剧本化改写，标注来源等级，不做分集切分。
- **B 产出「先导片」**：3 分钟独立交付物，只抛问题不揭答案。
- **C 产出「分集剧本 + 完整剧本」**：按分集规划切逐集，再合成连体整本。

每阶段产出结构化 package，通过「门禁」（必填字段齐全）才进下一阶段。

## 执行原则（贯穿全流程）

1. **上下文隔离**：每阶段只喂最小必要上下文，全文绝不重复加载。
2. **模型分层**：便宜模型干粗活，贵模型干细活。
3. **机械检查优先**：检索/对比类检查先用 Grep 机械跑，清掉低级错误才进模型。
4. **校验前置**：容易返工的点提前校验。
5. **复用件只生成一次**：开发圣经、人物小传、底牌分层表 + 禁词清单生成后直接引用。
