# 经济性（模型分层 + 机械检查分级）

> 对齐 `ip-script-pipeline` 的经济性原则，并借鉴「质检 P0~P2 门槛」思想：机械检查分级，P0 必过、P1 建议、P2 可选。

## 一、模型分层

| 任务 | 模型 | 理由 |
|---|---|---|
| 资产台账搬运、分镜表初稿、机械检查 | 便宜模型 | 结构化搬运，不需要创作力 |
| 构图/运镜设计、七段式提示词精修 | 贵模型 | 需要镜头语言判断力 |
| 成片关键镜提示词、文戏微表情拆格 | 贵模型 | 情绪颗粒度要求高 |

## 二、机械检查优先

分镜写完先跑 `tools/validate.py`（C1~C12 共 12 条检查码），拦下低级错误，再进语义审核。机械检查能拦下 60%+ 返工。

## 三、检查分级（P0~P2）

| 门槛 | 含义 | 典型检查项 |
|---|---|---|
| **P0**（必过，不过禁止交付） | 硬错误 | 换脸（同角色两镜面部描述不一致）/ 时长×语速超时 / 缺资产编号 / 缺字段 |
| **P1**（建议修） | 质量隐患 | 景别跳变超 2 级 / 越轴 / 运镜单调 / 关键动作未拆相位 / 安全转译（血腥敏感词） |
| **P2**（可选优化） | 锦上添花 | 情绪峰值校验 / 记忆点复用 / 金句气口标注 / 空镜节奏 |

## 四、上下文隔离

- 分镜表不重述资产描述（只引编号），避免把三件套全文反复喂进每个分镜任务。
- 每镜的提示词只带「本镜涉及的人物/场景/道具编号 + 对应字段」，不带全剧资产。
- 资产台账是「只读真源」，分镜/提示词任务只查不复制。

## 五、机械检查项清单（validate.py 实现，C1~C12）

1. 分镜号连续无跳号（C01）
2. 每镜字段齐全（C02）
3. 表尾合计时长 = 目标时长（误差 ≤0.5s，C03）
4. 每镜台词字数 ÷ 语速 ≤ 镜时长（C04）
5. 人物/场景/道具均用编号 P/S/D/V（C05）
6. 同角色跨镜面部描述一致，防换脸（C06）
7. 景别跳变 ≤2 级（C07）
8. 运镜/构图取值在词典内（C08）
9. 武戏关键动作拆相位（C09）
10. 越轴检测，同场戏机位在同侧（C10）
11. 安全转译检测，血腥/断肢敏感词（C11）
12. 情绪峰值校验，反杀峰值落在第 9 节拍（C12）
