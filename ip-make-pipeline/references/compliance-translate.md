# 动作戏安全转译词典（合规）

> 定位：把打戏/动作戏里的「血腥、断肢、重创」等平台敏感表达，统一转译成「气浪、火花、定格」等合规表达，降低过审风险。
> 铁律：**转译发生在「画面描述」与「成片提示词」两层**，不改变剧情走向，只换「视觉呈现方式」。
> 声明：本词典降低风险，**不承诺 100% 通过**平台审核，最终以平台规则为准。

---

## 一、为什么必须转译

模型对「血腥/断肢」类词的视觉呈现极其写实，一旦直接生成「断臂、喷血、脏器」，极易触发平台「暴力血腥」红线。而这些动作戏的**剧情功能**（胜负、重创、压制）可以通过「气浪、火花、定格」等价表达。

- **转译前**：「一刀砍断手臂，鲜血喷溅」→ 平台红线
- **转译后**：「刀光掠过，气浪震散，他半边身子一僵，重创定格」→ 合规且不损张力

---

## 二、核心转译词典

### 1. 血腥 → 气浪 / 火花 / 消散

| 敏感表达 | 合规转译 | 适用场景 |
|---|---|---|
| 鲜血喷溅 | 气浪震散 / 火花四溅 | 仙侠/玄幻打戏 |
| 血花四溅 | 光华绽开 / 能量涟漪 | 大招对轰 |
| 血流不止 | 气息紊乱 / 灵力流失 | 负伤状态 |
| 鲜血淋漓 | 伤痕泛光 / 衣襟凌乱 | 战后定妆 |
| 血肉模糊 | 重创定格 / 身形踉跄 | 受重击后 |

### 2. 断肢 → 重创定格 / 脱力

| 敏感表达 | 合规转译 | 适用场景 |
|---|---|---|
| 砍断手臂 | 一臂脱力垂落，重创定格 | 近身搏斗 |
| 斩断双腿 | 身形失衡，跪地定格 | 压制对手 |
| 断头 | 光影一闪，胜负已分（不拍落地） | 决胜一击 |
| 肢解 | 气劲震退，瘫软倒地 | 群战收束 |

### 3. 重创/致命 → 收束闭环（不拍死亡细节）

| 敏感表达 | 合规转译 | 适用场景 |
|---|---|---|
| 一刀毙命 | 剑光掠过，对手应声而倒 | 快速收尾 |
| 打穿胸口 | 气劲透体，身形一僵 | 仙侠内伤 |
| 砸成肉泥 | 重物砸落，尘土扬起，不见细节 | 坠物场景 |
| 血泊 | 一地狼藉 / 阴影静默 | 战后环境 |

## 三、三类打戏的转译差异

| 打戏类型 | 转译基调 | 示例 |
|---|---|---|
| **玄幻仙侠** | 用「气浪/光华/能量涟漪」替代一切物理创伤 | 「剑光掠过，气浪震散，胜负已分」 |
| **真人写实** | 用「定格/脱力/踉跄」替代血腥，保留写实质感 | 「一拳命中，他踉跄后退，重创定格」 |
| **通用打戏** | 用「火花/尘土/阴影」遮挡，留白处理 | 「刀光相交，火花四溅，尘土扬起」 |

## 四、转译的两种写法（落地位置）

### 写法 A：直接改画面描述（分镜表层）

分镜表的 `description` 字段，写合规版本，不写敏感原词。

- ❌ 分镜 7：「一刀砍断他的右臂，鲜血喷溅」
- ✅ 分镜 7：「刀光掠过，气浪震散，他右臂脱力垂落，重创定格」

### 写法 B：加进【强制禁止项】（提示词层）

如果分镜表仍保留了「负伤」语义，在七段式提示词的【强制禁止项】里加负面清单：

```
【强制禁止项】画面出现血腥、断肢、喷血、脏器外露等写实创伤；
一律以「气浪震散 / 火花四溅 / 重创定格」替代；不拍死亡落地细节。
```

## 五、检查码挂钩

本词典已接入 `tools/ipmake/validate.py` 的 **C11 检查码**：

- **C11（P1 建议）**：`description` / `dialogue` 是否含「喷血、断肢、砍断、血泊」等敏感词 → 命中则提示「建议按安全转译词典改写为气浪震散 / 火花四溅 / 重创定格」。
- **P0（必过，可选）**：若项目明确要求「合规锁」，可把敏感词命中从 P1 上调为 P0，未转译禁止投喂（当前默认 P1，不阻塞交付）。

> 另：`gate.py` 闸门5 做的是「违禁词清单」（绝对化用语），与本词典的「血腥/断肢转译」是两回事，二者互补，不重叠。

## 六、边界与免责

1. **不改变剧情**：转译只换「视觉呈现」，不删减「胜负/重创/压制」的剧情功能。
2. **不承诺过审**：平台规则动态变化，本词典是「降低风险」的工程手段，最终以平台审核为准。
3. **保留张力**：转译后的「气浪/定格」是仙侠短剧的成熟视觉语言，本身不减张力，甚至更「燃」。
