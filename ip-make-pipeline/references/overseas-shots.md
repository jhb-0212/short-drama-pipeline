# 海外剧分镜适配（赛道② 制作层）

> 定位：承接剧本层 `ip-script-pipeline/references/overseas-adapter.md` 产出的**英文对白剧本**，在本流水线里完成分镜。分镜规则**90% 复用国内剧**，只换「语言契约」这一层——对白英文、语速词/秒、全英文输出。
> 铁律：本文件只定义「差异」，不重复国内剧的完整规则（详见 `storyboard-format.md` 等）。凡本文件未提到的，一律按国内剧规则执行。

---

## 一、语言契约（唯一实质性差异）

| 维度 | 国内剧（①） | 海外剧（②） |
|---|---|---|
| 对白语言 | 中文 | 英文（北美英语，风格合同见剧本层 `overseas-adapter.md`） |
| 语速单位 | 字/秒（4.5~6.5） | **词/秒（约 2.0~2.8）** |
| 分镜表字段 | 中文填写 | 除 `shot_id` 外全部英文填写 |
| 提示词语言 | 中文指令 | 英文指令（直接喂海外视频模型） |
| 看板/SRT/CSV | 中文 | 英文（SRT 字幕为英文对白） |

### 语速硬校验换算

- 中文：`台词字数 ÷ 4.5~6.5 字/秒 ≤ 镜时长`
- 英文：`台词词数 ÷ 2.0~2.8 词/秒 ≤ 镜时长`

`validate.py` C04 的校验需按赛道切换语速单位。脚本通过分镜表 `language: "en"` 字段识别海外剧，自动切「词/秒」。

---

## 二、英文对白在分镜表里的写法

沿用剧本层 `overseas-adapter.md` 的「转译三铁律」（拆长句 / 去中文腔 / 贴人设口吻），分镜层额外约束：

1. **台词字段**：英文对白，标词数（不是字数）。例：`对白【Liam (firm): "Hand over the seal."】(4 words)`
2. **画面描述**：英文动作+环境，可演可拍，不写情绪形容词。例：`wheel crunches over snow-covered gravel`
3. **人物**：仍用资产编号 `P01`，但名字用海外角色名（剧本层已定名，分镜沿用，不改名）。

---

## 三、海外平台节奏重排（ReelShort / DramaBox 竖屏短剧）

海外竖屏短剧节奏与国内略有差异，分镜时注意：

| 维度 | 国内剧 | 海外剧 |
|---|---|---|
| 单镜时长 | 3~8s（默认 5s） | **2~6s（默认 4s）**，节奏更快 |
| 开场钩子 | 前 3 镜抓人 | **前 1~2 镜必须爆钩子**（海外观众跳出更快） |
| 台词密度 | 可稍密 | **更稀**（英文短句为主，避免长句） |
| 冲突前置 | 第 1 集末尾留悬念 | **每镜结尾都埋钩**（竖屏滑动随时切走） |

> 落到前置锁：海外剧的 **E 单镜时长上限**默认 4s，**D 段缝衔接**优先「换机位硬切」（海外观众对技巧转场容忍度更低，追求节奏）。

## 四、工具链改动

| 脚本 | 海外剧适配 |
|---|---|
| `validate.py` | C04 语速按 `language` 切「字/秒」vs「词/秒」；C05 资产引用、C08 运镜/构图、C11 安全转译均加了英文词库/别名（中英双语，向后兼容） |
| `prompt_build.py` | 七段式提示词输出英文（段名可保留中文标签，内容英文），强制禁止项/默认值按语言切换 |
| `board.py` | SRT/CSV/HTML 英文输出，feed.txt 英文投喂文本（`esc()` 已兼容非字符串字段） |
| `asset_check.py` | 无需改（资产编号 `P/S/D/V` 前缀与语言无关） |
| `gate.py` | 闸门4 人脸锚定按 `face_anchor` 的 Pxx 编号比对（与语言无关）；闸门5 违禁词加英文词库 |

> 实现方式：脚本读分镜表 JSON 顶层的 `language` 字段（`"zh"` 或 `"en"`），默认 `"zh"` 向后兼容国内剧。

## 五、与解说类（赛道③）的边界（硬提醒）

解说叙事**不走本流水线**，它是「旁白稿 VO Script + 素材剪辑」，不是分镜。若用户选赛道③，明确告知并**转交 `ip-jieshuo-pipeline`**（解说成片流水线，独立 skill）：

> 「解说类内容不需要分镜，它是旁白稿 + 画面素材匹配。剧本层 `jieshuo-script.md` 产出旁白稿 package 后，转 `ip-jieshuo-pipeline`（素材匹配 → 成片提示词 → 字幕 SRT → 解说看板）。本流水线（分镜 → 成片提示词）不适用。」

不要试图用分镜规则硬套解说稿。
