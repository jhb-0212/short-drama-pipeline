# 镜头语言（文武双模 + 运镜 + 景别）

> 借鉴「分镜」模块的「文武双模」思想：文戏、武戏分开建模，各有专属规则。分镜表「运镜/构图/景别」字段从本文件的词典取值，不自由发挥。

## 一、文戏（微表情驱动）

文戏靠「微表情 + 反应」推进，不靠大动作。拆镜粒度按「情绪推进」而非「动作推进」。

### 文戏微表情六阶段（一个情绪转折的拆格）

1. **察觉**：人物注意到什么（眼神微动/停顿）
2. **反应**：面部微表情（眉/嘴角/瞳孔）
3. **掩饰**：压住情绪（移开视线/转话题）
4. **对峙**：直视/逼近（可选，冲突戏）
5. **爆发/泄气**：情绪顶点或泄掉
6. **落点**：一句台词/一个动作收束

> 用六阶段拆「一场对话」里的关键情绪转折，而不是每句台词都拆一格。关键情绪节点拆细，过渡句一笔带过。

## 二、武戏（动作相位驱动）

武戏靠「动作相位拆格」推进，一个完整动作拆成多个相位，避免「一闪而过看不清」。

### 动作相位七态拆格（一个关键动作）

1. **预备**：起手/蓄力/眼神锁定
2. **发动**：动作启动
3. **过程**：动作进行中的关键帧（可拆 2~3 格）
4. **命中/接触**：打击点/接触瞬间
5. **反馈**：受击反应/物体反应
6. **收势**：动作收尾
7. **结果**：动作后果（倒地/破碎/位移）

> 关键动作（如「砸冰」「拔剑」「挡刀」）按七态拆格；过场动作（走路/转头）不拆，一镜带过。

### 武戏完播评分（自检）

- 动作是否「看得清」：关键相位是否都给到了？
- 节奏是否「有张弛」：快慢镜交替，不要全程一个速度？
- 打击是否有「反馈」：命中后有没有受击反应/破坏结果？

## 三、运镜 5 模式（从截图「运镜 5 模式」收敛）

| 模式 | 含义 | 适用 |
|---|---|---|
| 固定 | 机位不动，靠画面内运动 | 文戏对白、微表情 |
| 推/拉 | 靠近/远离主体 | 强调情绪（推）、揭示环境（拉） |
| 跟/移 | 跟随/横向移动 | 武戏追击、人物走位 |
| 升降 | 垂直运动 | 开场/结尾、空间揭示 |
| 快切/慢镜 | 节奏变化 | 紧张（快切）、抒情/关键瞬间（慢镜） |

> 每镜运镜从这 5 模式选一，标注具体（如「航拍持续下降」「贴地跟拍」），不写「随便动动」。

## 四、景别词典（8 级，从远到近）

大远景 → 远景 → 全景 → 中景 → 中近景 → 近景 → 特写 → 大特写

**景别连续性建议（P1，建议修）**：相邻镜的景别跳变建议不超过 2 级（如中景→特写 跳了 2 级可接受，中景→大特写 跳 3 级建议中间补一镜）。例外：情绪突转、强调细节可用「跳切」，但一场戏限 1~2 次。脚本 `validate.py` 的 C07 按 P1（建议）检查此条，不阻塞交付。

## 五、构图词典

对角线纵深 / 三分线 / 居中 / 对称 / 过肩 / 双人侧拍 / 框架构图 / 留白 / 前景遮挡

- 对话戏默认「过肩/正反打」；抒情戏用「留白」；压迫感用「前景遮挡 + 大远景」。
- 构图与站位绑定：先定站位（见 staging.md），再选构图，构图不能破坏 180° 轴线。
