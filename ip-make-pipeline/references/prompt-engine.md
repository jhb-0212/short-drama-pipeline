# 成片提示词引擎（七段式 + 禁令三改法）

> 借鉴「提示词七段式」与「禁令三改法」两条，这是成片提示词的黄金结构。产出给 Midjourney/即梦/可灵/ComfyUI 等生成工具。

## 一、七段式提示词结构（顺序即逻辑）

```
【画风风格】→【场景资产】→【核心人物】→【站位声明】→【时间轴分镜】→【音效】→【强制禁止项】
```

| 段 | 内容 | 来源 |
|---|---|---|
| ① 画风风格 | 视觉风格（写实/国风/电影感）+ 色调 + 光影逻辑 | 三件套「简介单·风格视听定调」 |
| ② 场景资产 | 场景编号 + 环境描述 | 资产台账 S 编号 |
| ③ 核心人物 | 人物编号 + 关键外貌锚定 | 资产台账 P 编号 + 定妆单 |
| ④ 站位声明 | 谁在哪、朝哪、关系位 | staging.md 站位声明 |
| ⑤ 时间轴分镜 | 这一镜的动作相位/微表情阶段（按秒） | 分镜表 |
| ⑥ 音效 | 音乐风格 + 关键音效 + 旁白 | 简介单「声音设计」 |
| ⑦ 强制禁止项 | 负面清单（见下「禁令三改法」） | 定妆单铁律 + 合规红线 |

> **【强制禁止项】只装负面清单**，单独放最后，不和其他段混写。正面要求放①~⑥，负面约束集中放⑦。

## 二、禁令三改法（禁令失效时的三种改法）

> 核心认知：**模型对否定不敏感、对词根敏感**。你说「不要斑点」，模型可能反而画出斑点。

| 改法 | 做法 | 示例 |
|---|---|---|
| **高关联概念换词** | 不说「不要 X」，改说「不要 X 的上位/下位概念」 | 不要说「不要狗」，说「画面中不出现四条腿的动物」 |
| **主体优先句式** | 先写「要什么」，再写「不要什么」 | 先写「柔和正面补光」，再写「无光斑」 |
| **触发器移除** | 删掉会触发错误的词，而不是加「不要」 | 不写「不要雀斑」，干脆不出现「斑」这个字 |

### 光斑禁令（定妆单铁律的提示词落地）

- ❌ 不要写「面部无光斑、无亮斑」（「光斑」「亮斑」本身就是触发器）
- ✅ 写「**柔和正面补光，面部受光均匀，无任何前景遮挡物投影**」（正向 + 移除触发器）

### 换脸禁令（防换脸的头号约束）

- ❌ 不要写「保持同一张脸」（模型不懂「同一张」）
- ✅ 写「**严格复用 P01 定妆单面部特征：<脸型/五官/发型/肤色逐项>**」——把定妆单字段直接抄进提示词，逐镜重复锚定

## 三、负面清单（强制禁止项标准内容）

每个提示词的⑦段，按需从以下取：

- 面部：无光斑、无亮斑、无斑点、无痘印、无疤痕（用「柔和补光」正向替代）
- 换脸：逐镜锚定定妆单（用「复用 P 编号面部特征」正向替代）
- 合规：无暴力血腥、无绝对化功效、无低俗（按目标平台红线）
- 违禁词：按 `ip-script-pipeline` 的禁词清单（若从剧本继承）

## 四、H3 支线（可选）

若目标工具支持 H3 模型（更细的镜头控制），⑦段式可自动转 **Ref2VA 六段式**（参考/视频/音频三段拆双）。本 skill 默认用七段式，H3 支线留给高级用户按需启用，不作为默认。
