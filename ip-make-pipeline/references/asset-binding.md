# 资产绑定与分级（Asset-First）

> 借鉴「Asset-First 资产包」思想：先把资产台账建好、分级定好，再拆分镜。分镜只引用编号，不重述资产。三件套（简介单/定妆单/资产清单）是唯一真源，本文件负责把它们**台账化 + 分级化**。

## 一、资产台账（编号规则）

| 前缀 | 含义 | 对应三件套 |
|---|---|---|
| P | 人物（Person） | 定妆单 + 资产清单「人物清单」 |
| S | 场景（Scene） | 资产清单「场景清单」 |
| D | 道具（Prop） | 资产清单「道具清单」 |
| V | 声音（Voice） | 资产清单「声音资产」 |

编号从 01 递增，全程唯一、不可复用。同一人物多套服装用 `P01-A / P01-B` 子编号，不换主编号（主编号=人脸，换装不换脸）。

## 二、资产 A/B/C 分级（决定投入多少算力）

> 这是经济性的核心：先定等级，再决定「出几个视角、投多少算力」，避免对每个资产平均用力。

| 等级 | 定义 | 资产要求 | 触发 |
|---|---|---|---|
| **A** | 主角 / 反派 / 关键剧情道具 | 满配：多视角、多表情、多服装，脸/道具纹路必须精确 | A0 建库即做 |
| **B** | 有戏份配角 / 常用场景 | 标准：正脸+侧脸，场景出关键角度即可 | A1 需要时做 |
| **C** | 群演 / 背景 / 一次性道具 | 复用：可贴图/可复用模板，不单独建资产 | A2 大量出现时才做 |

### A0~A3 按需触发（不一次性全做）

- **A0（建库）**：主角 + 反派 + 关键道具，开工就做，全片复用。
- **A1（补充）**：配角、常用场景，第一次出场前做。
- **A2（批量）**：群演、背景，同屏大量出现时才批量做。
- **A3（临时）**：一次性道具、过渡场景，用到才做，用完即弃。

## 三、资产要求细则（何时三视图 / 四面图）

- **人物**：A 级出「多视角 + 多表情 + 多服装」；B 级出「正脸+侧脸」；C 级只出「一张可复用图」。
- **场景**：会拍多个方向（角色在里面走动/转场）→ 四面图；只拍一个角度 → 单面图。不是每个场景都要四面图，别浪费算力。
- **道具**：会转动/多角度被拍到（关键剧情道具，如砸冰的石头、钥匙）→ 三视图；摆着不动 → 单体图。
- **声音**：对白角色需独立音色（V 编号），旁白可共用一个。

## 四、绑定纪律

1. 分镜表/提示词里，人物/场景/道具**一律只写编号**，不重述描述。
2. 发现分镜与台账描述打架 → **回改台账（或剧本）**，不在分镜里硬改。
3. 台账一旦定稿，全片所有图/视频生成都以它为准，不许中途漂移（尤其人脸）。
