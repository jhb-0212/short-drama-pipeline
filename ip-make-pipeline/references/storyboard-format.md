# 分镜表字段规范

> 字段以实际工作流（《逆境》分镜表 V1.6）为准，11 字段。这是「分镜层」的产物格式，承接资产台账（阶段①），产出后交给构图/运镜（阶段③）与成片提示词（阶段④）。
>
> **「11 字段」是表格版（人看）的口径**：其中「镜头号」「备注」「空镜标记」3 个字段在 JSON 里**没有独立 key**，而是被拆解/合并到其他 key（见下方「字段 ↔ JSON key 映射」的说明）。脚本消费的是 10 个 JSON key，二者不要混为一谈。

## 11 字段（每镜一行，全部填满）

| 字段 | 填写要求 | 示例（对标逆境表） |
|---|---|---|
| 分镜号 | 连续递增，1/2/3… | 1 |
| 镜头号 | 一镜可拆多格，用「分镜号+格号」如 1-1/1-2 | 1-1 |
| 建议时长 | 秒，整数或 .5，须通过「字数÷语速≤时长」校验 | 3s |
| 画面描述 | 这一镜里发生了什么，动作+环境，可演可拍，不写情绪形容词 | 车轮碾过积雪碎石、车身颠簸 |
| 人物 | 用资产编号 `P01 梁大`，不重述长相 | 人物资产：P01 梁大、P02 梁小 |
| 台词 | `{类型}【角色（语气）："..."】`，标字数 | 对白【梁小："好嘞邓总"】 |
| 运镜 | 从运镜词典取（推/拉/摇/移/跟/升降/手持/固定/快切/慢镜） | 航拍持续下降 |
| 构图 | 从构图词典取（对角线纵深/三分线/过肩/居中/对称） | 对角线纵深 |
| 景别 | 大远景/远景/全景/中景/中近景/近景/特写/大特写 | 大远景→中景 |
| 备注 | 资产引用 + 空镜标记 + 补拍说明 | 有车资产（P02 陆巡+EVX-9） |
| 空镜标记 | 无人物出场时标「空镜」，人物出场标「人物资产」 | 空镜；场景资产 |

## 字段 ↔ JSON key 映射（脚本输入）

上面的「表格版 11 字段」是给人看的，脚本消费的 JSON（`tools/ipmake/` 输入）用英文 key。映射关系：

| 表格字段 | JSON key | 说明 |
|---|---|---|
| 分镜号 | `shot_id` | 整数，1 起 |
| 建议时长 | `duration` | 秒，整数或浮点 |
| 画面描述 | `description` | 可演可拍的动作描述 |
| 人物 | `characters` | 如 `"P01 林梓泳 P02 沈青梧"` |
| 台词 | `dialogue` | 含「类型【角色（语气）：…】」的完整串，可空 |
| 运镜 | `camera` | 从运镜词典取 |
| 构图 | `composition` | 从构图词典取 |
| 景别 | `shot_size` | 从景别词典取 |
| 场景（编号） | `scene` | 如 `"S01 仙庭殿宇"` |
| 道具（编号） | `props` | 如 `"D01 时空锚印"`，可空 |

> 表格版「镜头号 / 备注 / 空镜标记」三字段在 JSON 里**无独立 key**，落点如下，写 JSON 时不要硬造同名字段：
> - **镜头号**（分镜号+格号 1-1/1-2）：JSON 里一个 shot 就是一个格，无需独立字段，`shot_id` 已够。
> - **备注**（资产引用 + 补拍说明）：资产引用已拆到 `characters`/`scene`/`props` 三个编号 key；补拍说明若需保留，并入 `description` 尾部括号注明。
> - **空镜标记**（空镜 vs 人物资产）：对应 `neutral_shot` 布尔字段（`true`=空镜/中性镜）。

> JSON 额外字段（表格版不要求、但脚本/质检会用到）：
> - `face_anchor`（防换脸锚点，C06 依赖，有人物必填）
> - `camera_side`（机位方向，C10 越轴检测用，取「左/右/空」）
> - `neutral_shot`（是否中性镜头，布尔，C10 越轴检测用：`true` 表示正对/背对镜头，可作换轴过渡，见 `staging.md` 轴线锁）
> - `is_action`（是否武戏镜，C09 拆相位检测用）
> - `tension`（情绪张力 0~10，C12 峰值校验用，可选）
> - 分镜表头部另有 `total`（合计行）、`transition`（段缝衔接）、`staging`（站位声明）、`style`（画风）字段。

## 表尾校验行（每条脚本必附）

分镜表末行必须有一行「合计」：总镜数 + 总时长，且 **Σ每镜时长 = 目标时长（误差 ≤0.5s）**。示例：`合计：18 镜 / 30.0s`。

> JSON 落盘时对应 `total` 字段：`"total": {"shots": 18, "duration": 30.0}`。`validate.py` 的 C03 会同时校验 `total.shots == 实际镜数` 与 `total.duration == Σ每镜时长`。

## 段缝衔接方式（多段任务必填）

短剧成片常由多段拼接（不同场/不同素材）。**段与段之间的衔接方式必须在前置锁 D 里选一，并写入分镜表头部 `transition` 字段**：

| 值 | 衔接方式 | 适用 |
|---|---|---|
| `freeze` | 末帧定格承接 | 上一段末帧定格，下一段从同一画面延续 |
| `hardcut` | 换机位硬切 | 直接切，节奏快，适合紧张戏 |
| `cutaway` | 空镜过渡 | 插空镜（天空/环境/物件）缓冲情绪 |
| `technique` | 技巧型转场 | 叠化/划像/闪白等特效转场 |

> JSON 落盘：`"transition": "cutaway"`。未指定则默认 `hardcut`（硬切），但在前置锁 D 未勾选时**必须停下询问**，不替用户默认。

## 三条硬约束（写作时同步执行）

1. **一镜一动作**：一镜只推进一个信息（一个动作/一句台词/一个反应），不塞两件事。塞了就拆镜。
2. **时长×语速**：每镜台词字数 ÷ 4.5~6.5 字/秒 ≤ 镜时长，超了要么删词要么加时长。
3. **资产只引编号**：分镜表里人物/场景/道具一律写 `P01/S03/D02` 这类编号，长相造型回查三件套，不在这里再写。

## 与资产台账的关系

分镜表引用的是阶段①产出的「资产台账」里的编号。台账编号规则见 `asset-binding.md`。分镜表只消费编号，台账才是描述真源——**发现分镜与台账对不上，回改台账或剧本，不在分镜里硬改**。
