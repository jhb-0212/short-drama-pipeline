# 站位声明与轴线锁（空间）

> 借鉴「空间」模块：站位声明四要素 + 轴线锁 + 位移链。这是分镜表「构图/景别」字段的**前置约束**——先声明人物站位，再定构图。多人戏最常犯的错就是「人物左右位置乱跳」「人站在画外」，本文件就是锁这些。

## 一、站位声明四要素（每场多人戏先写，再拆镜）

每场戏开拍前，先声明这一场的站位，写成一句话：

| 要素 | 含义 | 示例 |
|---|---|---|
| 谁 | 出场人物（编号） | P01 梁大、P02 梁小 |
| 在哪 | 空间位置（场景编号 + 相对方位） | S03 营地，靠湖一侧 |
| 朝哪 | 人物朝向/视线方向 | 梁大背对湖，面朝车队 |
| 关系位 | 谁在谁左/右/前/后 | 梁小在梁大右手边，邓总在两人对面 |

示例站位声明：`S03 营地，梁大背对冰湖站中央，梁小在其右手，邓总/琳琳在两人对面（面向营地）。`

## 二、180° 轴线锁

- 一场戏定一条**动作轴线**（人物视线连线或运动方向），所有机位只能待在轴线同侧。
- **越轴**（机位跳到轴线另一侧）会让两个对话的人瞬间「左右互换」，观众会懵。
- 例外：用「中性镜头」（正对/背对）或「运动镜头跨轴」过渡才可换轴，且只能换一次。
- **中性镜头落盘**：分镜表对应镜的 JSON 字段 `neutral_shot` 置 `true`（`camera_side` 可留空），表示该镜是正对/背对的中性镜头，`validate.py` 的 C10 越轴检测据此允许换轴过渡。

## 三、位移链（人物走动的连续性）

- 人物从一个位置走到另一个位置，必须拆成「起 → 动 → 止」至少三段，或一镜跟拍走完全程。
- 禁止「上一镜人在 A 点，下一镜直接瞬移到 B 点」无过程。
- 走位路径要能在分镜表里连成一条线（谁从哪走到哪、经过什么）。

## 四、硬纪律

1. **摆位必入画**：声明了站位的人，对应镜里必须出现在画面内，不许「人在场但镜头没拍到他」。
2. **人物账连续**：同一场戏，人物的左右/前后关系必须前后一致，不许上一镜梁小在左、下一镜跑到右（除非有位移链交代）。
3. **站位声明写进分镜表头部**：作为该场所有分镜的公共前提，后续每镜只写「相对站位的变化」，不重复声明。
