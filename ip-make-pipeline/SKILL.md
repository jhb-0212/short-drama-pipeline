# IP 制作层流水线（分镜 → 成片）

> 定位：衔接 `ip-script-pipeline`（剧本层）与成片生成工具（Midjourney/即梦/可灵/ComfyUI 等）。剧本层产出「三件套 + 完整剧本」，本流水线把它们**消费**成可拍摄/可生成的分镜表与提示词。
> 铁律：分镜只「引用资产编号」，不「重述资产描述」；三件套是唯一真源，分镜/提示词都锚定它，防止两处描述打架。

> **三条核心承诺**（都有脚本落地，不是口号）：
> - **不漂移**：角色/场景/道具先锁定再进分镜（Asset-First），跨镜一致性有据可依 → `asset_check.py` + C06 防换脸 + `series_check.py` 跨集回锚
> - **不返工**：错误拦在生成之前 → 🔒 前置锁 + 投喂必查清单 + P0~P2 门禁 + 六道闸门
> - **能直接投喂**：输出七段式提示词，整组复制即可喂模型 → `prompt_build.py` + `feed.txt`

## 🔒 前置锁（动手前强制勾选，硬门不是建议）

> 借鉴短剧制作系统的「六道前置锁」思路，并结合分镜层特点做了裁剪。**任何一道未指定，必须停下询问并把选项摆出来让用户勾选——禁止默认跳过、禁止替用户推断。**

| 锁 | 选项 | 说明 |
|---|---|---|
| **〇·0 赛道** | ① 国内剧 ② 海外剧 ③ 解说叙事 ④ 其他 | 第零道锁，先于一切。① 走完整四阶段；② 走完整四阶段，但**语言契约换英文**（对白英文、语速换「词/秒」、分镜表/提示词/看板全英文输出），规则见 `references/overseas-shots.md`；③ 解说叙事**不适用本流水线**（它产出旁白稿 VO Script，走素材剪辑，不是分镜），**转交 `ip-jieshuo-pipeline`**（解说成片流水线），明确告知并停；④ 停下询问 |
| **A 模型版本** | ① Seedance 2.5 ② Seedance 2.0 ③ MiniMax H3 ④ 其他 | 锁定后语法契约分流（H3 走 Ref2VA 六段式，见 `prompt-engine.md`） |
| **B 画幅** | ① 16:9 ② 9:16 ③ 21:9 | 与模型版本同规格前置锁定，未指定不动笔 |
| **C 交付形态** | ① 离线看板 ② md ③ 两者都交付 | ★ 强制锁，未指定 = 停下询问 |
| **D 段缝衔接方式** | ① 末帧定格承接 ② 换机位硬切 ③ 空镜过渡 ④ 技巧型转场 | 多段任务四选一，四项独立弹出 |
| **E 单镜时长上限** | 建议 3~8s（默认 5s 基准） | ★ 本流水线新增锁：分镜表最重要参数是单镜时长，超时会被语速校验拦下 |
| **I 画风锁** | 候选卡内勾选（含「按你的推荐走」） | 画风风格卡锁定后冻结，全片统一，禁止逐镜改画风 |

> 对比原「六道前置锁」的两处改进：
> 1. **补「时长锁 E」**——原系统漏了单镜时长这个分镜层最关键的参数，已补上。
> 2. **画风锁升级为「冻结资产」**——不是提示词里一段文字，而是锁定后全片统一、禁止逐镜漂移。

## 四阶段流程

```
① 资产绑定 → ② 分镜表 → ③ 构图/运镜 → ④ 成片提示词 → 交付看板
```

| 阶段 | 输入 | 产出 | 规则文件 | 工具 |
|---|---|---|---|---|
| ① 资产绑定 | 三件套 + 完整剧本 | 资产台账（A/B/C 分级 + 编号映射） | `references/asset-binding.md` | 人工/agent |
| ①.5 跨集一致性 | 资产台账 + 各集分镜表 | 跨集回锚报告（face/name 不漂移） | `references/series-consistency.md` | `series_check.py` |
| ② 分镜表 | 资产台账 + 剧本 | 逐镜分镜表（11 字段） | `references/storyboard-format.md` | `tools/validate.py` + `gate.py` |
| ③ 构图/运镜 | 分镜表 | 站位声明 + 构图方案 + 运镜标注 | `references/staging.md` + `shot-language.md` | `validate.py` |
| ④ 成片提示词 | 分镜表 + 构图 | 七段式提示词（正/负面） | `references/prompt-engine.md` | `prompt_build.py` |
| 交付 | 以上全部 | 离线分镜看板 | — | `board.py` |

## 三条核心铁律（贯穿全流程）

1. **分镜只引资产编号，不重述**：分镜表人物写 `P01 梁大`、场景写 `S03 营地`、道具写 `D02 陆巡`，长相/造型/材质一律回查三件套，不在分镜里再写一遍。

2. **防换脸是分镜层头号难题**：AI 生成最大坑是「同一角色换镜头就变脸」。每一镜的人物标注必须锚定定妆单编号，且成片提示词里**逐镜重复锚定**「一人一版、面部干净光洁、柔和正面补光、无光斑」。**跨集更要回锚定妆单**（`series_check.py`），防「第 1 集圆脸、第 10 集瓜子脸」的跨集换脸。

3. **时长与语速硬校验**：每镜台词字数 ÷ 语速（中文 4.5~6.5 字/秒）必须 ≤ 镜时长。机械检查拦下超时，才进语义审核。

## 经济性（模型分层 + 机械检查优先）

- **便宜模型**做资产台账搬运、分镜表初稿、机械检查；**贵模型**只做构图/运镜设计、七段式提示词精修、成片关键镜。
- **机械检查优先**：分镜写完先跑 `validate.py`（C1~C12 共 12 条检查码），拦下换脸/超时/缺编号/景别跳跃等 60%+ 低级错误，再进语义审核。详见 `references/economy.md`。
